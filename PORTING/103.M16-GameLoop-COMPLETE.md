## Architecture

```
GameLoop
├── state: GameState
│   ├── player: Player
│   ├── monster_manager: MonsterManager
│   ├── missile_manager: MissileManager
│   ├── item_manager: ItemManager
│   └── objects: Vec<Object>
├── timing: FrameTiming
├── triggers: Vec<Trigger>
├── level_type: LevelType
└── pending_transition: Option<LevelTransition>

run_frame():
┌─────────────────────────────┐
│ Check running state         │
├─────────────────────────────┤
│ For each tick iteration:    │
│   ├── game_logic()          │
│   │   ├── ProcessPlayers    │
│   │   ├── ProcessMonsters   │ (dungeon)
│   │   ├── ProcessObjects    │ (dungeon)
│   │   ├── ProcessMissiles   │
│   │   ├── ProcessItems      │
│   │   ├── ProcessTowners    │ (town)
│   │   └── CheckTriggers     │
│   └── Check break conditions│
├─────────────────────────────┤
│ Advance timing              │
└─────────────────────────────┘
```
