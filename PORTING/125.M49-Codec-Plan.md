## 2. 技术分析

### 2.1 random.cpp - 随机数系统

核心功能：
```cpp
// LCG (Linear Congruential Generator) - Borland C兼容
std::linear_congruential_engine<uint32_t, 0x015A4E35, 1, 0> diabloGenerator;

// Xoshiro128++ - 高质量种子生成
class xoshiro128plusplus;

// 设置随机种子
void SetRndSeed(uint32_t seed);

// 生成随机数
uint32_t GenerateRandomNumber();
int32_t AdvanceRndSeed();
int32_t GenerateRnd(int32_t v);

// 抛硬币
bool FlipCoin(unsigned frequency);
```

算法分析：
1. **LCG**: a=0x015A4E35, c=1, m=2^32 (Borland C兼容)
2. **Xoshiro128++**: 高质量PRNG，用于生成不可预测的种子
3. 种子管理：sglGameSeed 全局变量

依赖关系：
- 标准库 rotl (位旋转)
- chrono (时间种子)

### 3.2 核心结构
```rust
/// Borland C 线性同余生成器
/// a = 0x015A4E35, c = 1, m = 2^32
pub struct DiabloLcg {
    state: u32,
}

/// Xoshiro128++ 生成器
pub struct Xoshiro128PlusPlus {
    state: [u32; 4],
}

/// 游戏随机数管理器
pub struct GameRandom {
    lcg: DiabloLcg,
    seed_generator: Xoshiro128PlusPlus,
    game_seed: u32,
}
```

### 3.3 主要函数
```rust
impl GameRandom {
    /// 设置随机种子

    /// 生成随机数 (Borland LCG)
```
