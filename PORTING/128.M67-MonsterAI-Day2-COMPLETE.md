#### 1.1 `ai_skeleton()` - Basic Melee AI (~30 lines)
**C++ Reference**: `SkeletonAi()` monster.cpp:2051-2075

**Behavior**:
- **Intelligence-Based Decisions**: Uses monster intelligence for walk/attack probability
- **Delay Mode Check**: Checks `var1 == MonsterMode::Delay` for delayed actions
- **Distance-Based Logic**: Different behavior at distance ≥2 vs close range

**Key Logic**:
```rust
pub fn ai_skeleton(monster: &mut Monster) {
    if monster.mode != MonsterMode::Stand || monster.active_for_ticks == 0 {
        return;
    }

    let md = get_direction_to_enemy(monster);
    monster.facing = md;
    let distance = distance_to_enemy(monster);

    if distance >= 2 {
        // Far from enemy: 35-4*intelligence chance to walk
        if monster.var1 == MonsterMode::Delay as i16 ||
           rand::random::<i32>() % 100 >= 35 - 4 * monster.intelligence as i32 {
            random_walk(monster, md);
        } else {
            ai_delay(monster, 15 - (2 * intelligence) + random(10));
        }
    } else {
        // Close: 2*intelligence+20 chance to attack
        if monster.var1 == MonsterMode::Delay as i16 ||
           rand::random::<i32>() % 100 < 2 * monster.intelligence as i32 + 20 {
            start_attack(monster);
        } else {
            ai_delay(monster, (2 * (5 - intelligence)) + random(10));
        }
    }

    check_stand_animation(monster, md);
}
```

#### 1.2 `ai_scavenger()` - Corpse-Eating AI (~75 lines)
**C++ Reference**: `ScavengerAi()` monster.cpp:2129-2182

**Behavior**:
- **Auto-Healing**: Enters healing mode when HP < 50%
- **Pack Leaving**: Leaves pack when starting to heal
- **Corpse Search**: Searches for corpses within 4-tile radius
- **Eating Mechanics**: Heals based on Hellfire mode (HP/8 vs 64)
- **Fallback to Skeleton**: Uses skeleton AI when not healing

**Key Logic**:
```rust
pub fn ai_scavenger(monster: &mut Monster) {
    if monster.mode != MonsterMode::Stand {
        return;
    }

    // Enter healing mode at 50% HP
    if monster.hp < (monster.max_hp / 2) && monster.goal != MonsterGoal::Healing {
        if monster.leader_relation != LeaderRelation::None {
            // Leave pack
            monster.leader_relation = LeaderRelation::None;
        }
        monster.goal = MonsterGoal::Healing;
        monster.goal_var3 = 10; // Healing timer
    }

    // Healing mode
    if monster.goal == MonsterGoal::Healing && monster.goal_var3 != 0 {
        monster.goal_var3 -= 1;

        // Check if on corpse (placeholder until dungeon system)
        let has_corpse = false;

        if has_corpse {
            // Heal: HP/8 in Hellfire, 64 in vanilla
            let heal_amount = monster.max_hp / 8;
            monster.hp = (monster.hp + heal_amount).min(monster.max_hp);

            // Exit healing when full
            if monster.hp >= monster.max_hp {
                monster.goal = MonsterGoal::Normal;
                monster.goal_var1 = 0;
                monster.goal_var2 = 0;
            }
        } else {
            // Move towards corpse if found
            if monster.goal_var1 != 0 {
                let x = monster.goal_var1 as i32 - 1;
                let y = monster.goal_var2 as i32 - 1;
                monster.facing = Direction::from_delta(x - monster.x, y - monster.y);
                random_walk(monster, monster.facing);
            }
        }
    }

    // Fall back to skeleton AI
    if monster.mode == MonsterMode::Stand {
        ai_skeleton(monster);
    }
}
```

## 🎓 Key Learnings

### 1. Enum Value Alignment is Critical
Adding `Delay` mode required renumbering subsequent enum values:
```rust
// Before:
Charge = 14,
// After:
Delay = 14,
Charge = 15,  // All subsequent +1
```

**Lesson**: Always verify full enum alignment with C++ when adding missing variants

### 2. Type-Safe Enums Prevent Bugs
Using `LeaderRelation::None` instead of `0` catches type mismatches:
```rust
// ❌ Compiles in C++, silent bug in Rust
if monster.leader_relation != 0

// ✅ Rust enforces type safety
if monster.leader_relation != LeaderRelation::None
```

### 3. Placeholder Pattern for Dependencies
When dependencies aren't ready, use explicit placeholders:
```rust
// ✅ Clear placeholder with explanation

// ❌ Silent failure

```

**Pattern**: Implement foundational AIs first, complex ones can delegate
