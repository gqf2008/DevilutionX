### Rust Safety Improvements

The C++ code uses raw array indexing and mutable global state. Our Rust implementation:

1. **Encapsulation**: All state in `LightManager` struct
2. **Bounds Checking**: Safe array access with bounds validation
3. **Borrow Checker Compliance**: Restructured loops to avoid mutable borrow conflicts
4. **Debug Features**: Optional `disable_lighting` flag for debugging
