### 2.3 DialogueManager Quest Support (Part 3) - **67 lines**

**get_quest_dialogue() Method**:
```rust
impl DialogueManager {
    /// Get quest-specific dialogue for NPC (Day 98)
    /// C++ Reference: Quest check logic in TalkToX() functions
    pub fn get_quest_dialogue(&self, npc: TownerType, _player: &Player) -> Option<&DialogueNode> {
        match npc {
            TownerType::Smith => {
                if QuestId::Rock.is_active() {
                    return Some(&SMITH_QUEST_ROCK_START);
                }
                if QuestId::Anvil.is_active() {
                    return Some(&SMITH_QUEST_ANVIL_START);
                }
            }
            TownerType::Witch => {
                if QuestId::Mushroom.is_active() {
                    return Some(&WITCH_QUEST_MUSHROOM_TOME);
                }
            }
            TownerType::Story => {
                if QuestId::Betrayer.is_active() {
                    return Some(&STORYTELLER_QUEST_BETRAYER_START);
                }
            }
            _ => {}
        }
        None // STUB: Always None (quests inactive)
    }
}
```
