### 2.3 核心函数

| C++ 函数 | Rust 函数 | 说明 |
|----------|-----------|------|
| `SHA1CircularShift(word, bits)` | `sha1_circular_shift(word, bits)` | Diablo特殊循环左移 |
| `SHA1ProcessMessageBlock(context)` | `sha1_process_message_block(&mut context)` | 处理消息块 |

| `SHA1Calculate(context, data)` | `sha1_calculate(&mut context, data)` | 计算哈希 |

### 2.4 Diablo 特殊循环移位

标准 SHA1 循环左移:
```cpp
(word << bits) | (word >> (32 - bits))
```

Diablo X-SHA1 循环左移 (有符号算术右移):
```cpp
if ((word & (1 << 31)) != 0)
    return (0xFFFFFFFF << bits) | (word >> (32 - bits));
return (word << bits) | (word >> (32 - bits));
```

**关键区别**: 当最高位为1时，高位填充1而非0。

```rust
// 常量
pub const BLOCK_SIZE: usize = 16;
pub const SHA1_HASH_SIZE: usize = 5;

// Diablo SHA1 轮常量
const K: [u32; 4] = [0x5A827999, 0x6ED9EBA1, 0x8F1BBCDC, 0xCA62C1D6];

// 初始哈希值
const H_INIT: [u32; 5] = [0x67452301, 0xEFCDAB89, 0x98BADCFE, 0x10325476, 0xC3D2E1F0];

/// Diablo X-SHA-1 上下文
pub struct Sha1Context {
    pub state: [u32; SHA1_HASH_SIZE],
    pub buffer: [u32; BLOCK_SIZE],
}

impl Default for Sha1Context {
    fn default() -> Self {
        Self {
            state: H_INIT,
            buffer: [0; BLOCK_SIZE],
        }
    }
}

/// Diablo 特殊循环左移（带符号位扩展）
fn sha1_circular_shift(word: u32, bits: u32) -> u32;

/// 处理消息块
fn sha1_process_message_block(context: &mut Sha1Context);

/// 获取哈希结果
pub fn sha1_result(context: &Sha1Context) -> [u32; SHA1_HASH_SIZE];

/// 计算哈希
pub fn sha1_calculate(context: &mut Sha1Context, data: &[u32; BLOCK_SIZE]);
```
