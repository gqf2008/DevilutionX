### 7.2 架构优势

**DialogueManager vs C++ 隐式状态**:

**C++** (隐式):
```cpp
// 全局变量 (隐式状态)

    current_talk = TALK_SMITH;
```

**Rust** (显式):
```rust
pub struct DialogueManager {
    dialogues: HashMap<TalkId, &'static DialogueNode>,
    current_dialogue: Option<TalkId>, // 显式状态
}

impl DialogueManager {
    pub fn start_dialogue(&mut self, talk_id: TalkId, player: &Player) -> Option<&DialogueNode> {
        self.current_dialogue = Some(talk_id); // 状态更新
        self.get_dialogue(talk_id)
    }
}
```

**优势**:
- ✅ 状态可测试 (assert_eq!(manager.current_dialogue, Some(TalkId::Smith)))
