## 5. 技术注意事项

### 5.1 词缀效果类型映射

```rust
// item_dat.rs 中的枚举名称与 items.rs 中的使用对齐
DatEffectType::ArmorPercent => ItemEffectType::Ac,    // 不是 Ac
DatEffectType::ArmorPercentCurse => ItemEffectType::AcCurse,
DatEffectType::Life => ItemEffectType::HP,             // 不是 HP
DatEffectType::FastAttack => // 攻击速度               // 不是 AttackSpeed
DatEffectType::StealLife => // 生命偷取               // 不是 LifeSteal
DatEffectType::StealMana => // 法力偷取               // 不是 ManaSteal
```

### 5.2 rand 版本问题

项目使用较新版本的 `rand` crate，一些方法已被重命名：
- `thread_rng()` → `rng()`
- `gen_range()` → `random_range()`
- `gen_bool()` → `random_bool()`

这些会产生警告但不影响编译。
