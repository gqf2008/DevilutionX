### 2. 高速插值算法

**C++ Reference**: `Source/missiles.cpp:570-620`

```rust
pub fn check_intermediate_tiles<F>(
    start: Point,
    end: Point,
    velocity: Point,
    mut check_tile: F,
) -> Option<Point> {
    // 计算步进速度
    let denominator = if 2 * speed_y >= speed_x {
        2 * speed_y
    } else {
        speed_x
    };

    // 增量速度: (32 << 16) / denominator
    let inc_x = (velocity.x * (32 << 16)) / denominator;
    let inc_y = (velocity.y * (32 << 16)) / denominator;

    // 逐个检查中间瓦片
    for _ in 0..max_steps {
        traveled_x += inc_x;
        traveled_y += inc_y;

        let current_tile = convert_to_tile(...);
        if !check_tile(current_tile) {
            return Some(current_tile);  // 找到阻挡
        }
    }
}
```

**关键特性**:
- 自适应步进(根据速度分量)
- 完整路径扫描
- 提前终止(找到阻挡)
- 安全限制(防无限循环)
