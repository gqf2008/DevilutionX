### 1.1 msg.rs - 网络消息系统

**C++ 源文件**: `Source/msg.cpp` (~3491行), `Source/msg.h` (~766行)

**Rust 实现**: `src/game/msg.rs` (~900行)

#### 核心结构

##### 命令ID枚举 (CmdId)
```rust
pub enum CmdId {
    Stand = 0,      // 站立
    WalkXY = 1,     // 移动
    AckPlrInfo = 2, // 确认玩家信息
    AddStr = 3,     // 增加力量
    // ... 67个命令类型
    Pong = 66,      // Pong响应
}
```

##### 命令结构体
| 结构体 | 用途 | C++ 对应 |
|--------|------|----------|
| `TCmd` | 基础命令 (1字节) | `TCmd` |
| `TCmdLoc` | 位置命令 (3字节) | `TCmdLoc` |
| `TCmdParam1` | 单参数命令 | `TCmdParam1` |
| `TCmdParam2` | 双参数命令 | `TCmdParam2` |
| `TCmdLocParam1` | 位置+参数命令 | `TCmdLocParam1` |
| `TCmdLocParam4` | 法术命令 | `TCmdLocParam4` |
| `TCmdParam5` | 五参数命令 | `TCmdParam5` |
| `TCmdGItem` | 物品拾取命令 | `TCmdGItem` |
| `TCmdPItem` | 物品放置命令 | `TCmdPItem` |
| `TCmdChat` | 聊天消息 | - |
| `TSyncHeader` | 同步头 | `TSyncHeader` |
| `TSyncMonster` | 怪物同步 | `TSyncMonster` |
| `TCmdPlrInfoHdr` | 玩家信息头 | `TCmdPlrInfoHdr` |

##### 消息处理
```rust
pub struct MsgBuffer {
    data: Vec<u8>,
    read_pos: usize,
    write_pos: usize,
}

pub struct MsgHandler {
    local_player: u8,
    is_host: bool,
    recv_buffer: MsgBuffer,
    send_buffer: MsgBuffer,
}
```
