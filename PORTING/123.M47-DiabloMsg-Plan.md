## 2. 技术分析

### 2.1 核心数据结构

```cpp
struct MessageEntry {
    std::string text;
    uint32_t duration;  // 持续时间(ms)
};

std::deque<MessageEntry> DiabloMessages;  // 消息队列
uint32_t msgStartTime;                     // 开始时间
std::vector<std::string> TextLines;        // 显示行
```

### 2.2 消息字符串表

```cpp
const char *const MsgStrings[] = {

```

### 2.3 核心函数

| C++ 函数 | Rust 函数 | 说明 |
|----------|-----------|------|
| `InitDiabloMsg(e, duration)` | `init_msg(msg_id, duration)` | 按ID显示消息 |
| `InitDiabloMsg(msg, duration)` | `init_msg_text(text, duration)` | 按文本显示消息 |
| `IsDiabloMsgAvailable()` | `is_msg_available()` | 检查是否有消息 |
| `CancelCurrentDiabloMsg()` | `cancel_current_msg()` | 取消当前消息 |
| `ClrDiabloMsg()` | `clear_all_msgs()` | 清除所有消息 |
| `DrawDiabloMsg(out)` | `draw_msg(out)` | 绘制消息 |

### 2.4 消息类型枚举

包含神殿效果消息、保存消息、等级限制消息等。
