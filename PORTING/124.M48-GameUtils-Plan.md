# M48: 游戏工具模块移植计划

## 1. 概述

**M48目标**: 移植多个小型独立工具模块

**源文件分析**:

- `restrict.cpp` (~35行) - 文件系统只读测试
- `quick_messages.cpp` (~25行) - 快捷聊天消息
- `game_mode.cpp` (~20行) - 游戏模式状态

**总计**: ~80行 C++

## 2. 技术分析

### 2.1 restrict.cpp - 只读测试

```cpp
void ReadOnlyTest()
{
    // 测试能否在配置目录写入文件
    const std::string path = paths::PrefPath() + "Diablo1ReadOnlyTest.foo";
    SDL_IOStream *file = SDL_IOFromFile(path.c_str(), "w");
    if (file == nullptr) {
        DirErrorDlg(paths::PrefPath());
    }
    SDL_CloseIO(file);
    RemoveFile(path.c_str());
}
```
