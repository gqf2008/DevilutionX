## 🎓 技术要点

### 1. 经验表实现
**原 C++ 方式**: 运行时从 TSV 文件加载
**Rust 方式**: 编译期常量数组 `const EXP_LEVELS`

优势:
- 零运行时开销 (查表 O(1))
- 类型安全 (编译期检查)
- 无文件 I/O 依赖

### 2. 固定点数值
生命/法力增长使用 `<< 6` 定点数:
```rust
adj_life: 2048,  // 32 << 6 = 32.0
lvl_life: 128,   // 2 << 6 = 2.0
chr_life: 96,    // 1.5 << 6 = 1.5 (Monk)
```

### 3. 职业标志位掩码
```rust
// Barbarian 有两个标志
class_flags: PlayerClassFlag::IronSkin as u8
           | PlayerClassFlag::NaturalResistance as u8
```
