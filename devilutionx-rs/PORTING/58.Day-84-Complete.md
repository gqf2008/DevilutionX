### 1. load_dun_file() - Binary File I/O

**Location**: drlg_l4.rs:1439-1537 (99 lines)

**Features**:
```rust
fn load_dun_file(&mut self, filename: &str, dungeon: &mut Dungeon, x: i32, y: i32) -> bool {
    use std::fs::File;
    use std::io::Read;

    // 1. File reading
    let mut file = match File::open(filename) {
        Ok(f) => f,
        Err(_) => return false, // Graceful failure
    };

    // 2. Header parsing (little-endian)
    let width = u16::from_le_bytes([buffer[0], buffer[1]]) as usize;
    let height = u16::from_le_bytes([buffer[2], buffer[3]]) as usize;

    // 3. Validation
    if width == 0 || height == 0 || width > 100 || height > 100 {
        return false; // Sanity check
    }

    // 4. Size verification
    let expected_size = 4 + (width * height * 2);
    if buffer.len() != expected_size {
        return false; // Exact match required
    }

    // 5. Tile placement (row-major)
    for j in 0..height {
        for i in 0..width {
            let tile_id = u16::from_le_bytes([...]) as u8;
            if tile_id == 0 { continue; } // Skip transparent

            // Bounds check
            if px >= 0 && px < DMAXX && py >= 0 && py < DMAXY {
                dungeon.tiles[px][py] = tile_id;
            }
        }
    }

    true // Success
}
```

**Key Design Decisions**:
1. **Graceful Failure**: Returns `false` instead of panicking
2. **Exact Size Check**: Prevents truncated/corrupted files
3. **Overflow Protection**: `checked_mul()` for large dimensions
4. **Tile 0 Skip**: Matches C++ transparent tile behavior
5. **Bounds Safety**: No out-of-bounds writes

**Error Handling**:
- File not found → false
- Read error → false
- Invalid header → false
- Size mismatch → false
- Out of bounds tiles → skip silently

```rust
fn load_diablo_quads(&mut self, dungeon: &mut Dungeon, preflag: bool) {
    let (hold_x, hold_y) = self.l4_hold;

    // Quad 1 (SW): diab1.dun (always, no a/b)
    let quad1_x = hold_x as i32 + 4;
    let quad1_y = hold_y as i32 + 4;
    self.load_dun_file("levels/l4data/diab1.dun", dungeon, quad1_x, quad1_y);

    // Quad 2 (NE): diab2a/b.dun
    let quad2_file = if preflag { "diab2b.dun" } else { "diab2a.dun" };
    self.load_dun_file(quad2_file, dungeon, 27 - hold_x, 1 + hold_y);

    // Quad 3 (NW): diab3a/b.dun
    let quad3_file = if preflag { "diab3b.dun" } else { "diab3a.dun" };
    self.load_dun_file(quad3_file, dungeon, 1 + hold_x, 27 - hold_y);

    // Quad 4 (SE): diab4a/b.dun
    let quad4_file = if preflag { "diab4b.dun" } else { "diab4a.dun" };
    self.load_dun_file(quad4_file, dungeon, 28 - hold_x, 28 - hold_y);
}
```

**Position Formulas** (match C++ exactly):
```
Quad 1: (hold_x + 4, hold_y + 4)
Quad 2: (27 - hold_x, 1 + hold_y)
Quad 3: (1 + hold_x, 27 - hold_y)
Quad 4: (28 - hold_x, 28 - hold_y)
```

**Preflag Logic**:
- `preflag = true` (before stairs): Use 2b/3b/4b variants
- `preflag = false` (after stairs): Use 2a/3a/4a variants
- Purpose: Prevent stair/quad conflicts
