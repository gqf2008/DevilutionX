## 🎯 技术亮点

### 1. 常量数组设计
使用 Rust 的 `const` 数组特性,在编译时完成所有数据初始化:
```rust
pub const MONSTERS_DATA: [MonsterData; NUM_DEFAULT_MTYPES] = [
    // 138 个怪物数据
];
```
优点:
- 零运行时开销
- 类型安全
- 编译时验证

### 2. 宏定义简化
使用 `mdat!` 宏简化数据定义,提高可读性:
```rust
macro_rules! mdat {
    ($name:expr, $dlvl_min:expr, ...) => {
        MonsterData { ... }
    };
}
```

### 3. 抗性系统
使用位标志实现怪物抗性:
```rust
pub struct MonsterResistance(pub u8);

impl MonsterResistance {
    pub const IMMUNE_MAGIC: Self = Self(1 << 3);
    pub const IMMUNE_FIRE: Self = Self(1 << 4);
    pub const IMMUNE_LIGHTNING: Self = Self(1 << 5);
    // ...
}
```

### 4. 类型安全枚举
使用 `#[repr(i16)]` 确保与 C++ 的 ABI 兼容:
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[repr(i16)]
pub enum MonsterId {
    ZombieN = 0,
    // ... 138 types
    NaKrul = 137,
    Invalid = -1,
}
```

## 🐛 已解决问题

### 问题 1: 数组大小不匹配
**错误:** `expected array [MonsterData; 138] found array [MonsterData; 55]`

### 问题 2: 抗性组合表示
**挑战:** C++ 使用位或运算符 `|`,Rust const 上下文限制
**解决:** 使用 `MonsterResistance(value1 | value2)` 直接构造
