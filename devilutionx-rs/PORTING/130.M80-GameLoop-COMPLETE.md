# M80 Playable Demo - Complete Game Loop Implementation

## 概述

完成了DevilutionX Rust的完整游戏循环实现,对齐C++ Source/diablo.cpp的生产代码架构。

## 实现架构

### 三层循环结构

```
RunGameLoop()           ← 外层包装器(初始化+主循环)
  └─ game_loop()        ← 迭代控制器(3次/每逻辑更新)
      └─ GameLogic()    ← 核心游戏逻辑
```

### 双速循环架构

- **快速路径** (60 FPS): 输入 + 网络 + 渲染
- **逻辑路径** (2 Hz / 500ms): 游戏状态更新

```
每帧 (16.67ms):
├─ 事件处理 (HandleEvent)
├─ 时间检查 (has_500ms_passed)
└─ 分支:
    ├─ 快速路径 (如果<500ms):
    │  ├─ ProcessInput()
    │  ├─ process_network_packets()
    │  └─ [可选] 渲染
    │
    └─ 逻辑路径 (如果≥500ms):
       ├─ process_game_message_packets()
       ├─ game_loop_iteration() (3次):
       │  ├─ handle_delta()      (网络同步)
       │  ├─ game_logic()         (状态更新)
       │  └─ clear_last_sent_cmd()
       ├─ color_cycling_logic()
       └─ 渲染
```

## C++ 源代码参考

### Source/diablo.cpp:857 - RunGameLoop()
```cpp
void RunGameLoop(interface_mode uMsg) {
    StartGame(uMsg);
    SetEventHandler(GameEventHandler);
    run_delta_info();

    while (gbRunGame) {
        // 事件处理
        while (FetchMessage(&event, &modState)) {
            HandleMessage(event, modState);
        }

        // 时间检查
        bool runGameLoop = nthread_has_500ms_passed(&drawGame);

        if (!runGameLoop) {
            // 快速路径
            ProcessInput();
            DvlNet_ProcessNetworkPackets();
            if (drawGame) RedrawViewport(), DrawAndBlit();
            continue;
        }

        // 逻辑路径
        ProcessGameMessagePackets();
        if (game_loop(gbGameLoopStartup))
            diablo_color_cyc_logic();

        if (drawGame) DrawAndBlit();
    }

    PaletteFadeOut(8);
}
```

### Source/diablo.cpp:3416 - game_loop()
```cpp
bool game_loop(bool bStartup) {
    const uint16_t wait = bStartup ? sgGameInitInfo.nTickRate * 3 : 3;

    for (unsigned i = 0; i < wait; i++) {
        if (!multi_handle_delta()) {
            TimeoutCursor(true);
            return false;
        }
        TimeoutCursor(false);
        GameLogic();
        ClearLastSentPlayerCmd();

        if (!gbRunGame || !gbIsMultiplayer || !nthread_has_500ms_passed())
            break;
    }
    return true;
}
```

### Source/diablo.cpp:1510 - GameLogic()
```cpp
void GameLogic() {
    if (!ProcessInput()) return;

    if (gbProcessPlayers) {
        ProcessPlayers();
    }

    if (leveltype != DTYPE_TOWN) {
        ProcessMonsters();
        ProcessObjects();
        ProcessMissiles();
        ProcessItems();
        ProcessLightList();
        ProcessVisionList();
    } else {
        ProcessTowners();
        ProcessItems();
        ProcessMissiles();
    }

    sound_update();
    CheckTriggers();
    CheckQuests();
    RedrawViewport();
    pfile_update(false);
    plrctrls_after_game_logic();
}
```
