## 📝 技术要点

### 与 objdat.rs 集成
```rust
use super::data::objdat::{ObjectId, get_object_data};

// 使用 objdat 数据创建对象
let data = get_object_data(ObjectId::Chest1);
let obj = Object {
    id: ObjectId::Chest1,
    solid: data.flags.solid,
    breakable: data.flags.breakable,
    animation_len: data.anim_len,
    // ...
};
```

### 对象 ID 管理
```rust
// C++ 使用索引数组,Rust 使用 Vec + ID
pub struct ObjectManager {
    objects: Vec<Option<Object>>,  // 稀疏数组
    next_id: usize,
}

// 或使用 HashMap
pub struct ObjectManager {
    objects: HashMap<usize, Object>,
    next_id: usize,
}
```

### 动画系统
```rust
impl Object {
    pub fn update_animation(&mut self, delta_time: u32) {
        self.animation_timer += delta_time;
        if self.animation_timer >= self.animation_delay {
            self.animation_timer = 0;
            self.animation_frame = (self.animation_frame + 1) % self.animation_len;
        }
    }
}
```

## ⚠️ 注意事项

1. **对象 ID 映射**: C++ 使用固定数组索引,Rust 需要灵活的 ID 管理
2. **动画状态**: 注意与渲染系统的接口设计
3. **交互优先级**: 同一位置多个对象时的选择逻辑
4. **保存/加载**: 预留序列化接口
5. **网络同步**: 考虑多人游戏的状态同步
