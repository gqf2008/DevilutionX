## *_new.rs 文件分析结论

经过详细审查，`*_new.rs` 文件 (item_new.rs, quest_new.rs, objects_new.rs, player_new.rs, monster_new.rs, level_new.rs) 是用于 **Save/Load 兼容性** 的精确 C++ 结构映射，应该 **保留**：

| 文件 | 行数 | 用途 |
|------|------|------|
| item_new.rs | 747 | C++ Item 结构精确映射 |
| quest_new.rs | 1,009 | Quest + SpeechId 枚举 |
| objects_new.rs | 772 | Object + ObjectId 枚举 |
| player_new.rs | 749 | Player 结构精确映射 |
| monster_new.rs | 661 | Monster 结构精确映射 |
| level_new.rs | 695 | DungeonType, SetLevel, Difficulty |

这些文件与主实现文件 (items.rs, quests.rs, objects.rs 等) 是 **互补关系**，不是重复：
- 主文件: 游戏逻辑实现
- *_new.rs: 存档二进制兼容性
