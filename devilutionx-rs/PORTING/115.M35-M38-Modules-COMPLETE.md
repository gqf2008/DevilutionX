## M37: 鼠标追踪系统 (track.rs)

### 功能
- 光标下目标检测（怪物/物体/玩家）
- 目标有效性验证
- 玩家动作重复机制
- 滚动/行走状态追踪

### 主要结构
```rust
pub struct TrackingState {
    pub cursor_monster: i32,
    pub cursor_object: Option<usize>,
    pub cursor_player: Option<usize>,
    pub cursor_position: Point,
    pub last_action: PlayerActionType,
    pub mouse_down: ClickType,
    pub cursor_type: CursorType,
}

pub struct TargetTracker {
    pub state: TrackingState,
}

pub struct ActionRepeater {
    pub enabled: bool,
    pub repeat_delay_ms: u32,
}
```

### C++ → Rust 映射
| C++ 函数 | Rust 方法 |
|----------|-----------|
| `InvalidateTargets()` | `TargetTracker::invalidate_targets()` |
| `RepeatPlayerAction()` | `ActionRepeater::should_repeat()` |
| `track_isscrolling()` | `TrackingState::is_scrolling()` |

### 枚举类型
- `PlayerActionType` - 玩家动作类型
- `ClickType` - 点击类型
- `CursorType` - 光标类型
- `TargetType` - 目标类型
- `RepeatAction` - 重复动作类型
