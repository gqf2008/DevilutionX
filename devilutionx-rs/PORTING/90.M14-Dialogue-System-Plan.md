## 3. Rust实现设计

### 3.1 核心数据结构

#### DialogueOption (对话选项)
```rust
/// Single dialogue option in a conversation tree.
///
/// **C++ Reference**: Implicit in `TalkToBlackSmith()` etc.
#[derive(Debug, Clone)]
pub struct DialogueOption {
    /// Display text (e.g., "Let me see what you have to sell")
    pub text: &'static str,

    /// Next TalkId to transition to
    pub next_talk_id: TalkId,

    /// Condition function (e.g., "has items to sell")
    pub condition: fn(&Player) -> bool,
}

impl DialogueOption {
    pub const fn new(
        text: &'static str,
        next_talk_id: TalkId,
        condition: fn(&Player) -> bool,
    ) -> Self {
        Self { text, next_talk_id, condition }
    }

    pub fn is_available(&self, player: &Player) -> bool {
        (self.condition)(player)
    }
}
```

#### DialogueNode (对话节点)
```rust
/// Dialogue tree node for NPC conversations.
///
/// **C++ Reference**: `TalkToBlackSmith()` in `Source/towners.cpp`
#[derive(Debug, Clone)]
pub struct DialogueNode {
    /// Current TalkId (e.g., TalkId::Smith)
    pub talk_id: TalkId,

    /// Greeting text (optional)
    pub greeting: Option<&'static str>,

    /// Available dialogue options
    pub options: &'static [DialogueOption],
}

impl DialogueNode {
    pub fn get_available_options(&self, player: &Player) -> Vec<&DialogueOption> {
        self.options
            .iter()
            .filter(|opt| opt.is_available(player))
            .collect()
    }
}
```

#### DialogueManager (对话管理器)
```rust
/// Manages all NPC dialogue trees.
///
/// **C++ Reference**: Implicit in towner interaction system
pub struct DialogueManager {
    /// Map: TalkId -> DialogueNode
    dialogues: HashMap<TalkId, DialogueNode>,

    /// Current active dialogue (if any)
    current_dialogue: Option<TalkId>,
}

impl DialogueManager {
    pub fn new() -> Self;
    pub fn start_dialogue(&mut self, talk_id: TalkId) -> Option<&DialogueNode>;
    pub fn select_option(&mut self, option_index: usize, player: &Player) -> Result<TalkId, DialogueError>;
    pub fn end_dialogue(&mut self);
}
```
