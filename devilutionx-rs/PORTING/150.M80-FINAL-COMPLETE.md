## 五、关键技术实现

### 5.1 双速游戏循环

**问题**: C++使用500ms间隔更新逻辑,60 FPS渲染
**解决方案**: GameTiming系统分离逻辑/渲染频率

```rust
pub struct GameTiming {
    last_logic_time: Instant,
    logic_interval: Duration, // 500ms
}

impl GameTiming {
    pub fn has_500ms_passed(&mut self, draw_flag: &mut bool) -> bool {
        let now = Instant::now();
        let elapsed = now.duration_since(self.last_logic_time);

        if elapsed >= self.logic_interval {
            self.last_logic_time = now;
            *draw_flag = true;
            true  // 运行逻辑
        } else {
            *draw_flag = true;
            false // 跳过逻辑
        }
    }
}
```

### 5.2 等距坐标系统

**问题**: 屏幕坐标↔世界坐标转换
**解决方案**: 数学变换矩阵

```rust
pub struct TilePosition {
    pub x: i32,
    pub y: i32,
}

impl TilePosition {
    pub fn to_screen(&self, camera: Point) -> (i32, i32) {
        let iso_x = (self.x - self.y) * 32;
        let iso_y = (self.x + self.y) * 16;
        (iso_x - camera.x, iso_y - camera.y)
    }

    pub fn from_screen(screen_x: i32, screen_y: i32, camera: Point) -> Self {
        let world_x = screen_x + camera.x;
        let world_y = screen_y + camera.y;

        let tile_x = (world_x / 32 + world_y / 16) / 2;
        let tile_y = (world_y / 16 - world_x / 32) / 2;

        Self { x: tile_x, y: tile_y }
    }
}
```

### 5.3 CEL解码优化

**问题**: 原始CEL格式压缩,需要转换为CLX
**解决方案**: 逐字节解码+透明处理

```rust
pub fn decode_cel_to_clx(cel_data: &[u8]) -> Result<ClxSprite> {
    let mut clx_data = Vec::new();
    let mut i = 0;

    while i < cel_data.len() {
        let byte = cel_data[i];

        if byte >= 128 {
            // 透明像素
            let count = (256 - byte as usize) as u8;
            clx_data.push(count);
            i += 1;
        } else {
            // 不透明像素
            let count = byte;
            clx_data.push(count | 0x80);
            for _ in 0..count {
                i += 1;
                clx_data.push(cel_data[i]);
            }
            i += 1;
        }
    }

    Ok(ClxSprite::new(clx_data))
}
```

### 7.2 遇到的问题及解决

**问题1**: SDL2 EventPump所有权冲突
**解决**: 每帧创建新的EventPump

**问题2**: 等距坐标计算精度
**解决**: 使用整数运算避免浮点误差

**问题3**: 游戏循环帧率不稳定
**解决**: 添加wait_for_frame精确控制

**问题4**: 类型推断歧义
**解决**: 显式类型标注`let half_width = 32i32;`
