## 目标

将 `dialogue.rs` 中的 stub 函数替换为实际调用 `player.rs` 和 `inventory.rs` 的真实实现。

## ✅ 已完成工作

### 1. DialoguePlayer Trait (接口抽象) ✅

定义了 `DialoguePlayer` trait 使 dialogue 模块可以查询玩家状态而不直接依赖具体实现：

```rust
pub trait DialoguePlayer {
    fn gold(&self) -> i32;
    fn level(&self) -> u8;
    fn has_item(&self, item_id: u32) -> bool;
    fn has_visited_level(&self, level: usize) -> bool;
    fn inventory_count(&self) -> usize;
}
```

### 2. StubPlayer 实现 ✅

创建了可配置的测试用 Player 实现，支持 builder 模式：

```rust
let player = StubPlayer::new()
    .with_gold(500)
    .with_level(10)
    .with_quest_items(&[9, 17, 33])  // Rock, Mushroom, LazStaff
    .with_visited_levels(&[1, 5, 9]);
```

### 3. Player 实现 DialoguePlayer ✅

在 `player.rs` 中为 `Player` struct 实现了 trait：

```rust
impl DialoguePlayer for Player {
    fn gold(&self) -> i32 { self.stats.gold as i32 }
    fn level(&self) -> u8 { self.level as u8 }
    fn has_item(&self, _item_id: u32) -> bool { false } // TODO: Full Inventory
    fn has_visited_level(&self, level: usize) -> bool {
        Player::has_visited_level(self, level)
    }
    fn inventory_count(&self) -> usize { 0 }
}
```

### 4. 泛型 Helper 函数 ✅

更新了 `has_quest_item()` 和 `has_visited_level()` 使用泛型：

```rust
pub fn has_quest_item<P: DialoguePlayer>(player: &P, item_id: u32) -> bool {
    player.has_item(item_id)
}

pub fn has_visited_level<P: DialoguePlayer>(player: &P, level: u8) -> bool {
    player.has_visited_level(level as usize)
}
```
