```rust
#[derive(Debug, Clone)]
pub struct DialogueOption {
    /// Display text shown to the player
    pub text: &'static str,

    /// Next TalkId to transition to
    pub next_talk_id: TalkId,

    /// Condition function (e.g., "has items to sell")
    pub condition: fn(&Player) -> bool,
}

impl DialogueOption {
    pub const fn new(
        text: &'static str,
        next_talk_id: TalkId,
        condition: fn(&Player) -> bool,
    ) -> Self;

    pub fn is_available(&self, player: &Player) -> bool;
}
```

## 5. 技术亮点

### 5.1 零成本抽象

**函数指针条件检测**:
```rust
pub condition: fn(&Player) -> bool
```

**优势**:
- ✅ 编译期类型检查
- ✅ 零运行时开销 (直接函数调用)
- ✅ 易于测试 (纯函数)

---

### 5.2 编译期常量

**const fn 构造函数**:
```rust
pub const fn new(...) -> Self { ... }
```

**优势**:
- ✅ 对话树在编译期构建 (零运行时开销)
- ✅ 无堆分配
- ✅ 可放入 `.rodata` 段 (只读内存)

---

### 5.3 静态数据

**零拷贝字符串**:
```rust
pub text: &'static str
pub options: &'static [DialogueOption]
```

**优势**:
- ✅ 无字符串分配
- ✅ 无数组复制
- ✅ 编译期检查生命周期

---

### 5.4 类型安全

**TalkId枚举**:
```rust
pub next_talk_id: TalkId  // 不是 i32/u8
```

**优势**:
- ✅ 编译期检查状态有效性
- ✅ 无效状态无法表示
- ✅ 模式匹配完整性检查
