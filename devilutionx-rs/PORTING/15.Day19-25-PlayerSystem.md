## 🔧 Key Features

### 1. Fixed-Point HP/Mana System

```rust
/// HP Precision: 64x
pub const HP_PRECISION: i32 = 64;

// Internal: _p_hit_points = actual_hp * 64
// Display: _p_hit_points >> 6
// Modify: add/subtract raw 64x values

player.set_hp(50);              // Stores 3200 internally
assert_eq!(player.get_hp(), 50); // Displays 50
```

**Why 64x?**
- C++ uses bitshifts for performance: `hp >> 6` = divide by 64
- Allows fractional HP without floating point
- Matches DevilutionX exactly

## 🔍 Key Insights

### 1. Fixed-Point System

**C++ Pattern**:
```cpp
player._pHitPoints = player._pMaxHP;           // Full heal
player._pHitPoints = std::min(player._pHitPoints, player._pMaxHP); // Clamp
if (player._pHitPoints >> 6 <= 0) { /* Dead */ }
```

**Rust Implementation**:
```rust
self._p_hit_points = self._p_max_hp;           // Full heal
self._p_hit_points = self._p_hit_points.clamp(0, self._p_max_hp); // Clamp
if self._p_hit_points == 0 { /* Dead */ }
```

### 2. Base vs Current Stats

**Base**: Permanent value from levels/equipment
**Current**: Base + temporary bonuses (buffs/shrines)

Example:
```rust
_p_base_str = 30;  // From levels
_p_strength = 35;  // Base + 5 from Strength shrine
```

### 3. Percentage System

C++ uses integer percentages for UI display:
```cpp
int percent = (hp * 100) / max_hp;
```

Rust equivalent:
```rust
fn get_hp_percentage(&self) -> i32 {
    if self._p_max_hp == 0 { return 0; }
    ((self._p_hit_points as i64 * 100) / self._p_max_hp as i64) as i32
}
```

**Note**: Use `i64` to prevent overflow on multiplication

## 🎓 Lessons Learned

### 1. Fixed-Point Arithmetic
- **Challenge**: Matching C++ bitshift behavior (`>> 6`)
- **Solution**: Use `HP_PRECISION` constant, explicit conversions
- **Benefit**: No floating-point errors, exact C++ match

### 2. Percentage Overflow
- **Issue**: `(hp * 100)` can overflow i32 for high max HP
- **Solution**: Cast to i64 before multiplication
- **Code**: `((self._p_hit_points as i64 * 100) / self._p_max_hp as i64) as i32`

### 3. Death Detection
- **C++ Pattern**: `if (hp >> 6 <= 0)` (display value check)
- **Rust Pattern**: `if hp == 0` (internal value check)
- **Equivalence**: Both detect death correctly
