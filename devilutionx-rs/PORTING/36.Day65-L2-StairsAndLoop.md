```rust
/// Place stairs in the dungeon (USTAIRS, DSTAIRS, and optionally WARPSTAIRS)
fn place_stairs(&mut self, dungeon: &mut Dungeon, _entry: LevelEntry) -> bool {
    // 放置上行楼梯
    if !self.place_miniset(dungeon, &miniset_ustairs()) {
        return false;
    }
    // 放置下行楼梯
    if !self.place_miniset(dungeon, &miniset_dstairs()) {
        return false;
    }
    // L5 特殊: 放置传送门 (Warp Stairs)
    if self.current_level == 5 {
        if !self.place_miniset(dungeon, &miniset_warpstairs()) {
            return false;
        }
    }
    true
}
```

**关键逻辑**:
- 按顺序放置 3 个 miniset (USTAIRS → DSTAIRS → WARPSTAIRS)
- L5 特殊处理: 额外放置传送门
- 任何一个失败都返回 `false`,触发重试

### 2. PlaceMiniSet - 随机位置搜索 (18 lines)

```rust
/// Try to randomly place a miniset in the dungeon
fn place_miniset(&mut self, dungeon: &mut Dungeon, miniset: &Miniset) -> bool {
    const MAX_ATTEMPTS: usize = 1000;
    for _ in 0..MAX_ATTEMPTS {
        let x = self.random_range(0, (DMAXX - miniset.width) as usize) as i32;
        let y = self.random_range(0, (DMAXY - miniset.height) as usize) as i32;
        let pos = Point::new(x, y);
        if self.try_place_miniset(dungeon, miniset, pos) {
            return true;
        }
    }
    false
}
```

**关键逻辑**:
- 随机生成 `(x, y)` 坐标 (确保 miniset 不超出边界)
- 调用 `try_place_miniset` 验证并放置
- 最多尝试 1000 次 (与 C++ 一致)
- 全部失败返回 `false`

**C++ 对齐度**: 100%

### 3. TryPlaceMiniSet - 模式匹配与替换 (50 lines)

```rust
/// Try to place a miniset at a specific position
fn try_place_miniset(&mut self, dungeon: &mut Dungeon, miniset: &Miniset, pos: Point) -> bool {
    // 1. 边界检查
    if pos.x < 0 || pos.y < 0 {
        return false;
    }
    if pos.x + miniset.width >= DMAXX || pos.y + miniset.height >= DMAXY {
        return false;
    }

    // 2. 模式匹配: 验证 search values
    for dy in 0..miniset.height {
        for dx in 0..miniset.width {
            let search_idx = (dy * miniset.width + dx) as usize;
            let search_val = miniset.search[search_idx];

            // search value 含义:
            // 0: 任意图块 (always match)
            // 1-4, 7: 必须精确匹配 dungeon.tiles
            if search_val != 0 {
                let dungeon_x = (pos.x + dx) as usize;
                let dungeon_y = (pos.y + dy) as usize;
                let current_tile = dungeon.tiles[dungeon_y][dungeon_x];

                if current_tile != search_val {
                    return false; // 不匹配,放置失败
                }
            }
        }
    }

    // 3. 应用替换: 将 replace values 写入 dungeon.tiles
    for dy in 0..miniset.height {
        for dx in 0..miniset.width {
            let replace_idx = (dy * miniset.width + dx) as usize;
            let dungeon_x = (pos.x + dx) as usize;
            let dungeon_y = (pos.y + dy) as usize;
            dungeon.tiles[dungeon_y][dungeon_x] = miniset.replace[replace_idx];
        }
    }

    true
}
```

**关键逻辑**:
- **边界检查**: 确保 miniset 完全在 dungeon 范围内
- **模式匹配**:
  - `search_val = 0`: 通配符,匹配任意图块
  - `search_val != 0`: 必须精确匹配当前图块值
- **图块替换**: 将 `miniset.replace` 数组写入 `dungeon.tiles`

**C++ 对齐度**: 100% (完整实现 C++ 逻辑)

### 4. Generate 方法 - 重试循环 (38 lines)

```rust
pub fn generate(&mut self, dungeon: &mut Dungeon, _seed: u32, level: u8) -> bool {
    self.current_level = level;

    // 主生成循环 (最多重试 100 次)
    let max_retries = 100;
    for _attempt in 0..max_retries {
        self.reset();

        if self.create_dungeon(dungeon) {
            self.fix_tiles_patterns(dungeon);
            self.fix_transparency(dungeon);

            // 尝试放置楼梯
            if !self.place_stairs(dungeon, LevelEntry::MainEntry) {
                continue; // 失败则重试整个生成过程
            }
            break; // 成功则跳出循环
        }
    }

    // 后处理 (在重试循环外执行)
    self.fix_lockout(dungeon);
    self.fix_doors(dungeon);
    self.fix_dirt_tiles(dungeon);

    true
}
```

**重要改进**:
- **重试循环**:
  - C++ 使用 `while (1)` 无限循环,Rust 改为 `max_retries = 100`
  - 防止无限循环导致的挂起
- **楼梯放置失败处理**:
  - `place_stairs` 返回 `false` → `continue` 重试
  - 成功 → `break` 跳出循环
- **后处理优化**:
  - `fix_lockout`, `fix_doors`, `fix_dirt_tiles` 移到循环外
  - 避免重复执行 (C++ 也是如此)

**C++ 对齐度**: 95% (改进了循环安全性)
