## Architecture

### Item Flow Diagram

```text
  [Cursor/HeldItem]
         │
    ┌────┴────┐
    │         │
    ▼         ▼
[Inventory] [Belt]
 (40 slots) (8 slots)
    │
    ▼
[Equipment]
 (7 slots)
```

### Grid Encoding

```text
InvGrid[i]:
- -1         : Empty cell
- n >= 0     : Item index (bottom-left cell of item)
- -(n+1) < 0 : Part of item n (not bottom-left)
```

### Paste Logic Flow

```text
paste_item(item, slot, size):
  1. check_overlapping_items()
     - If multiple items: FAIL
     - If no items: place directly
     - If one item: continue to swap

  2. If gold onto gold:
     - merge_gold() and return

  3. swap_with_existing()
     - Remove existing item
     - Place new item
     - Return displaced item
```
