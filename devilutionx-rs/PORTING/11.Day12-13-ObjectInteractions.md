## Rust 特有设计

### 1. 枚举类型替代魔法数字

**C++**:
```cpp
#define DOOR_CLOSED 0
#define DOOR_OPEN 1
#define DOOR_BLOCKED 2

door._oVar4 = DOOR_OPEN;
```

**Rust**:
```rust
pub enum DoorState {
    Closed = 0,
    Open = 1,
    Blocked = 2,
}

door.ovar4 = DoorState::Open as i32;
let state = DoorState::from(door.ovar4);
```

**优势**:
- 类型安全: 编译期检查
- 可读性: `DoorState::Open` vs `1`
- 双向转换: `From<i32>` 和 `Into<i32>`

### 2. 模式匹配替代 switch

**C++**:
```cpp
switch (object._otype) {
case OBJ_L1LDOOR:
case OBJ_L1RDOOR:
    OperateDoor(object, sendmsg);
    break;
// ...
}
```

**Rust**:
```rust
match object.otype {
    ObjectId::L1LDoor | ObjectId::L1RDoor => {
        operate_door(object, send_network_msg)
    }
    // ...
}
```

**优势**:
- 穷尽性检查 (exhaustiveness)
- 更清晰的分组语法
- 直接返回结果

### 3. Option 替代 nullptr

**C++**:
```cpp
Object* FindObjectAtPosition(Point pos) {
    // ...
    return nullptr;  // 找不到
}
```

**Rust** (未来实现):
```rust
fn find_object_at_position(pos: Point) -> Option<&Object> {
    // ...
    None  // 找不到
}
```

**优势**:
- 强制错误处理
- 消除空指针异常
- `if let Some(obj) = ...` 语法

## 实现细节

### Door System

**状态机**:
```
Closed --[operate]--> Open
  ↑                     ↓
  └─────[operate]───────┘
        (if clear)

Open --[operate if blocked]--> Blocked
Blocked --[operate if clear]--> Closed
```

**动画同步**:
- Open: `anim_frame = anim_len - 1` (最后一帧)
- Closed: `anim_frame = 0` (第一帧)
- Solid flag: Closed=true, Open=false

## 关键决策记录

### 1. 枚举 vs 常量

**选择**: 使用 `enum DoorState` 和 `enum ChestItemMode`
**理由**:
- 类型安全: 编译期检查防止无效值
- 可读性: `DoorState::Open` 比 `1` 更清晰
- 扩展性: 添加新状态无需修改常量

**权衡**:
- 需要 `From` trait 转换 (i32 ↔ enum)
- 轻微内存开销 (enum discriminant)

### 2. Stub vs 完整实现

**选择**: 关键逻辑 stub,核心框架完整
**理由**:
- 依赖未实现系统 (Item, Missile, Sound)
- 避免循环依赖
- 允许独立测试核心逻辑

**计划**:
- Phase 1: Day 12-13 框架 ✅
- Phase 2: Day 14-15 特殊对象
- Phase 3: 后续集成 Item/Missile/Sound
