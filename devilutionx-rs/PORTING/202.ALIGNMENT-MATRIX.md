## 5. 已移植代码中的已知行为偏差（待修复，按优先级）

1. **光照/视野（深度核实 2026-08-01）**：C++ 快照**无** `MakeLight`——真实机制为径向 `DoLighting` + 射线 `DoVision` + `dPreLight` + 多光源 `ProcessLightList`。已移植 `cast_vision_rays`（VisionRays 表 + 四象限 + 对角线遮挡）；`Dungeon.light/pre_light` 默认值已对齐 C++ `defaultLight`（0 town/15 地牢，7bf225347）。可玩关卡（L1/town）渲染光照基底**已与 C++ 一致**；`DoVision` 属 automap/探索范畴（C++ 渲染不以 dFlags::Visible 门控）。待办：L2–L4 静态光（lava/火盆）→ dPreLight → 渲染管线。
2. **透明度（已实现主体 2026-08-01）**：`FloodTransparencyValues`（span-fill，gendung.cpp:820/286）已移植并接入 L1 布局（00a53e5ef）；`scrollrt` 已按 C++:540 接入 `TransList[dTransVal[tile]]`，`draw_cell` 使用 getFirstTileMaskLeft/Right + 墙体 Transparent mask，`render_world_pipeline` 按 DoVision markTransparentFn 填充 TransList（1737a44f0）。待办：C++ L1 `FixTransparency`（Dirt 墙传播）、门/窗对象放置。
3. **foliage（已完成 2026-08-01）**：`RenderTileFoliage`/`GetDunFrameFoliage`（dun_render.hpp:132/162）已移植（776defcf0），`draw_cell` 地板 TransparentSquare tile 渲染 16 行 foliage 层（y-16..y-31）。
4. **实体/HUD 入面**：实体 overlay 已统一到 `tile_screen_position`（64f98e886），但未绘入调色板面；HUD/DrawMain 未入面。
5. **多关卡衔接**：L2–L4 生成已移植，但全流程关卡切换/楼梯（L1→L2→L3→L4 + town 回程）未端到端验证。
6. **存档互操作**：save 格式目标为 C++ 兼容，但未用真实 C++ 存档做字节级往返测试。
7. **Timedemo 全量回放**：`tests/timedemo_e2e.rs` 的 `replay_warrior_level1to2`（C++ gold 字节比对）仍 `#[ignore]`。

## 7. 更新方法

每完成一个子系统/修复一个偏差：

1. 更新本矩阵对应行的状态与证据（附 C++ 行号引用或测试名）。
2. 运行 `cargo test`（全目标），确认 0 失败。
3. 提交（Conventional Commits），如 `feat: port MakeLight flood-fill` / `fix: ...`。
4. 完成“未移植”行后，将对应空壳目录从 `src/` 移除或接入模块图，并更新第 1 节总览。
