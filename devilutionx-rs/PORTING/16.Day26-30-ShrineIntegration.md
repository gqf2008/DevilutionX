## 🔍 Example Implementation

### Mysterious Shrine (Most Complex)

```rust
pub fn apply_mysterious(player: &mut Player, random_stat: CharacterAttribute) {
    // Decrease all attributes by 1
    let str_val = player.get_base_attribute(CharacterAttribute::Strength);
    player.set_base_attribute(CharacterAttribute::Strength, str_val - 1);

    let mag_val = player.get_base_attribute(CharacterAttribute::Magic);
    player.set_base_attribute(CharacterAttribute::Magic, mag_val - 1);

    let dex_val = player.get_base_attribute(CharacterAttribute::Dexterity);
    player.set_base_attribute(CharacterAttribute::Dexterity, dex_val - 1);

    let vit_val = player.get_base_attribute(CharacterAttribute::Vitality);
    player.set_base_attribute(CharacterAttribute::Vitality, vit_val - 1);

    // Increase random attribute by 6
    let current = player.get_base_attribute(random_stat);
    player.set_base_attribute(random_stat, current + 6);
}
```

**Usage in `objects.rs`:**

```rust
ShrineType::Mysterious => {
    let mut rng = rand::rng();
    let random_stat = match rng.random_range(0..4) {
        0 => CharacterAttribute::Strength,
        1 => CharacterAttribute::Magic,
        2 => CharacterAttribute::Dexterity,
        _ => CharacterAttribute::Vitality,
    };
    shrine_effects::apply_mysterious(player, random_stat);
}
```

## 📝 Notes

### Design Decisions

1. **Separate Module**: Created `shrine_effects.rs` instead of inline in `objects.rs`
   - **Rationale**: Separation of concerns (object state vs. player effects)
   - **Benefit**: Easier testing, clear API boundaries

2. **Random Number Generation**: Used `rand::rng()` for shrine effects
   - **Matches**: Item affix system pattern
   - **Future**: May need deterministic seed for multiplayer

3. **Dummy Player**: `interact_with_object()` creates temporary player
   - **Reason**: Game state not yet integrated
   - **TODO**: Pass actual player reference from game loop

### Known Limitations

- Light radius modification doesn't update rendering yet
- Gold loss in Mendicant shrine is stubbed (requires inventory system)
- Potion spawning in Divine shrine is stubbed (requires item generation)

### C++ Compatibility

- All effects match DevilutionX behavior
- Stat modifications use 64x fixed-point precision
- HP/Mana restoration uses Player system methods
