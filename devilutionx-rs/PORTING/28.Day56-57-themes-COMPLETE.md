## 🔧 核心算法

### 1. add_theme - 添加主题

```rust
pub fn add_theme(&mut self, ttype: ThemeId, ttval: i8) -> bool {
    if self.numthemes >= MAXTHEMES {
        return false;  // 超过最大限制
    }

    // 添加主题
    self.themes[self.numthemes] = ThemeStruct { ttype, ttval };
    self.numthemes += 1;

    // 更新单次出现标志
    match ttype {
        ThemeId::ArmorStand => self.armor_flag = true,
        ThemeId::WeaponRack => self.weapon_flag = true,
        ThemeId::Treasure => self.treasure_flag = true,
        ThemeId::Cauldron => self.cauldron_flag = true,
        ThemeId::Library => self.zharlib = (self.numthemes - 1) as i32,
        ThemeId::BloodFountain => self.b_fountain_flag = true,
        ThemeId::MurkyFountain => self.m_fountain_flag = true,
        ThemeId::PurifyingFountain => self.p_fountain_flag = true,
        ThemeId::TearFountain => self.t_fountain_flag = true,
        _ => {}
    }

    true
}
```

**对齐**: 100% (C++ `themes[numthemes++] = {t, ttval}` 逻辑)

### 2. check_theme_reqs - 主题需求检查

```rust
pub fn check_theme_reqs(&self, theme: ThemeId) -> bool {
    match theme {
        // 无限制主题(可重复出现)
        ThemeId::Shrine | ThemeId::SkelRoom | ThemeId::Library
        | ThemeId::MonstPit | ThemeId::Barrel | ThemeId::Torture
        | ThemeId::Decapitated | ThemeId::BrnCross | ThemeId::GoatShrine => true,

        // 单次出现主题
        ThemeId::ArmorStand => !self.armor_flag,
        ThemeId::WeaponRack => !self.weapon_flag,
        ThemeId::Treasure => !self.treasure_flag,
        ThemeId::Cauldron => !self.cauldron_flag,

        // 喷泉限制(每种喷泉每关只能一次)
        ThemeId::BloodFountain => !self.b_fountain_flag,
        ThemeId::MurkyFountain => !self.m_fountain_flag,
        ThemeId::PurifyingFountain => !self.p_fountain_flag,
        ThemeId::TearFountain => !self.t_fountain_flag,

        ThemeId::None => false,
    }
}
```

## 🎓 技术要点

### 1. 单次出现限制设计

某些主题每关只能出现一次(避免奖励重复):
```rust
match theme {
    ThemeId::ArmorStand => !self.armor_flag,
    ThemeId::WeaponRack => !self.weapon_flag,
    ThemeId::Treasure => !self.treasure_flag,
    ThemeId::Cauldron => !self.cauldron_flag,
    // 4 种喷泉也有单次限制
    ThemeId::BloodFountain => !self.b_fountain_flag,
    // ...
}
```

### 2. 喷泉系统的四种限制

4 种喷泉主题各自独立计数:
- `BloodFountain` → `b_fountain_flag`
- `MurkyFountain` → `m_fountain_flag`
- `PurifyingFountain` → `p_fountain_flag`
- `TearFountain` → `t_fountain_flag`

每关可以同时存在 4 种喷泉,但每种只能一次。

### 3. Zhar 任务特殊处理

Zhar 是一个 NPC,出现在 Library 主题中:
```rust
if has_zhar_quest {
    self.zharlib = 0;  // 标记 Library 主题索引
    // 完整实现会强制创建 Library 主题
}
```

### 4. 主题变量用途

`themex`, `themey`, `theme_var1` 是内部状态,用于 `Theme_*` 函数:
- `themex`, `themey`: 主题房间中心坐标
- `theme_var1`: 主题特定变量(如怪物数量、物品数量)

这些在 `create_theme_rooms()` 中每个主题重置为 0。

```rust
pub fn hold_theme_rooms(&mut self, dungeon: &mut Dungeon) {
```
