## C++ 数据结构分析

### PLStruct (Prefix/Suffix Data)
```cpp
struct PLStruct {
    std::string PLName;              // 词缀名称
    ItemPower power;                 // 效果类型 + value1 + value2
    int8_t PLMinLvl;                 // 最低等级要求
    AffixItemType PLIType;           // 适用物品类型 (bit flags)
    enum goodorevil PLGOE;           // Good/Evil/Any alignment
    uint8_t PLChance;                // 生成概率权重
    bool PLOk;                       // 是否有用 (useful)
    int minVal;                      // 最小价值
    int maxVal;                      // 最大价值
    int multVal;                     // 价值乘数
};
```

### AffixItemType (bit flags)
```cpp
enum AffixItemType : uint8_t {
    PLT_NONE      = 0,
    PLT_MISC      = 1 << 0,  // 0x01 - Ring, Amulet
    PLT_BOW       = 1 << 1,  // 0x02 - Bow
    PLT_STAFF     = 1 << 2,  // 0x04 - Staff
    PLT_WEAPON    = 1 << 3,  // 0x08 - Sword, Axe, Mace
    PLT_SHIELD    = 1 << 4,  // 0x10 - Shield
    PLT_ARMOR     = 1 << 5,  // 0x20 - Armor, Helm
};
```
