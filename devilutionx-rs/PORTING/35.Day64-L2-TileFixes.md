## 🎯 实现目标

### 1. FixTransparency (透明度修正)
**目的**: 为特定瓷砖组合复制透明度值

**算法**:
```rust
fn fix_transparency(&self, dungeon: &mut Dungeon) {
    // 使用2x2块索引映射 dungeon[i][j] → trans_val[xx][yy]
    let mut yy = 16;
    for j in 0..DMAXY {
        let mut xx = 16;
        for i in 0..DMAXX {
            // 规则1: 瓷砖14 + 上方瓷砖10
            if j > 0 && dungeon.tiles[i][j] == 14 && dungeon.tiles[i][j-1] == 10 {
                dungeon.trans_val[xx+1][yy] = dungeon.trans_val[xx][yy];
                dungeon.trans_val[xx+1][yy+1] = dungeon.trans_val[xx][yy];
            }
            // 规则2-5: 瓷砖11/14/15/16的其他组合...
            xx += 2;
        }
        yy += 2;
    }
}
```

**关键点**:
- **2x2索引映射**: `xx = 16 + i*2`, `yy = 16 + j*2`
- **5条规则**: 针对瓷砖10/11/14/15/16的特定组合
- **透明度复制**: 将一个位置的透明度值复制到相邻位置
- **坐标系统**: trans_val使用MAXDUNX×MAXDUNY (112×112), dungeon使用DMAXX×DMAXY (40×40)

**C++对齐**:
- ✅ 完全匹配C++逻辑
- ⚠️ C++缺少边界检查 (已在Rust中添加)
- ✅ 5条规则全部实现

### 2. FixDirtTiles (泥土瓷砖修正)
**目的**: 修正泥土瓷砖边界以保证视觉一致性

**算法**:
```rust
fn fix_dirt_tiles(&self, dungeon: &mut Dungeon) {
    for j in 0..DMAXY {
        for i in 0..DMAXX {
            // 右邻居检查 (3条规则)
            if i+1 < DMAXX {
                if dungeon.tiles[i][j] == 13 && dungeon.tiles[i+1][j] != 11 {
                    dungeon.tiles[i][j] = 146; // 13 → 146
                }
                if dungeon.tiles[i][j] == 11 && dungeon.tiles[i+1][j] != 13 {
                    dungeon.tiles[i][j] = 144; // 11 → 144
                }
                if dungeon.tiles[i][j] == 15 && dungeon.tiles[i+1][j] != 14 {
                    dungeon.tiles[i][j] = 148; // 15 → 148
                }
            }
            // 下邻居检查 (3条规则)
            if j+1 < DMAXY {
                if dungeon.tiles[i][j] == 10 && dungeon.tiles[i][j+1] != 12 {
                    dungeon.tiles[i][j] = 143; // 10 → 143
                }
                if dungeon.tiles[i][j] == 13 && dungeon.tiles[i][j+1] != 11 {
                    dungeon.tiles[i][j] = 146; // 13 → 146
                }
                if dungeon.tiles[i][j] == 14 && dungeon.tiles[i][j+1] != 12 {
                    dungeon.tiles[i][j] = 147; // 14 → 147
                }
            }
        }
    }
}
```

**关键点**:
- **6条替换规则**: 3条右邻居 + 3条下邻居
- **边界安全**: 添加 `i+1 < DMAXX` 和 `j+1 < DMAXY` 检查 (C++缺少)
- **瓷砖映射**:
  - 10 → 143 (无下邻居12)
  - 11 → 144 (无右邻居13)
  - 13 → 146 (无右邻居11 或 无下邻居11)
  - 14 → 147 (无下邻居12)
  - 15 → 148 (无右邻居14)

**C++对齐**:
- ✅ 6条规则全部实现
- ⚠️ Rust添加边界检查 (C++有潜在缓冲区溢出风险)
- ✅ 瓷砖替换逻辑完全匹配

### 3. FixLockout (门廊道修正)
**目的**: 确保所有门廊道至少有一个门瓷砖,防止玩家被锁定

**算法** (3-Pass):
```rust
fn fix_lockout(&self, dungeon: &mut Dungeon) {
    // Pass 1: 修正畸形门瓷砖
    for j in 0..DMAXY {
        for i in 0..DMAXX {
            // 垂直门 (瓷砖4) 左边必须是墙 (瓷砖3)
            if i > 0 && dungeon.tiles[i][j] == 4 && dungeon.tiles[i-1][j] != 3 {
                dungeon.tiles[i][j] = 1; // 4 → 1 (地板)
            }
            // 水平门 (瓷砖5) 上方必须是墙 (瓷砖3)
            if j > 0 && dungeon.tiles[i][j] == 5 && dungeon.tiles[i][j-1] != 3 {
                dungeon.tiles[i][j] = 2; // 5 → 2 (地板)
            }
        }
    }

    // Pass 2: 水平廊道 (确保至少1个门瓷砖5)
    for j in 1..(DMAXY-1) {
        for i in 1..(DMAXX-1) {
            // 检测水平廊道: (瓷砖2或5) 且 上下都是墙3
            if (tiles[i][j] == 2 || tiles[i][j] == 5)
                && tiles[i][j-1] == 3 && tiles[i][j+1] == 3 {

                // 扫描廊道直到结束
                let mut doorok = false;
                let mut scan_i = i;
                while scan_i < DMAXX-1
                    && (tiles[scan_i][j] == 2 || tiles[scan_i][j] == 5)
                    && tiles[scan_i][j-1] == 3 && tiles[scan_i][j+1] == 3 {

                    if tiles[scan_i][j] == 5 {
                        doorok = true; // 找到门
                    }
                    scan_i += 1;
                }

                // 如果没有门,在末端放置一个
                if !doorok && scan_i > i {
                    tiles[scan_i-1][j] = 5;
                }
            }
        }
    }

    // Pass 3: 垂直廊道 (确保至少1个门瓷砖4)
    // 类似Pass 2,但扫描垂直方向
}
```

**关键点**:
- **3-Pass算法**:
  - **Pass 1**: 修正畸形门 (左/上无墙的门转为地板)
  - **Pass 2**: 水平廊道验证 (tile 5)
  - **Pass 3**: 垂直廊道验证 (tile 4)
- **廊道检测**:
  - 水平: `(tile==2或5) && 上下==3`
  - 垂直: `(tile==1或4) && 左右==3`
- **门保证**: 如果廊道没有门,在末端放置一个

**C++对齐**:
- ✅ 3-Pass逻辑完全匹配
- ✅ 廊道扫描算法一致
- ⚠️ Protected区域检查已注释 (需Day 70实现Protected bitset)
- ✅ doorok标志逻辑正确

### 4. FixDoors (门类型调整)

**算法**:
```rust
fn fix_doors(&self, dungeon: &mut Dungeon) {
    for j in 1..DMAXY {
        for i in 1..DMAXX {
            // 垂直门 + 上方墙 → 瓷砖7
            if dungeon.tiles[i][j] == 4 && dungeon.tiles[i][j-1] == 3 {
                dungeon.tiles[i][j] = 7;

            // 水平门 + 左墙 → 瓷砖9
            if dungeon.tiles[i][j] == 5 && dungeon.tiles[i-1][j] == 3 {
                dungeon.tiles[i][j] = 9;
            }
        }
    }
}
```

**关键点**:
- **2条规则**:
  - 垂直门 (4) + 上墙 (3) → 瓷砖7
  - 水平门 (5) + 左墙 (3) → 瓷砖9
- **简单替换**: 无复杂逻辑,仅基于邻居检查

**C++对齐**:
- ✅ 100% 匹配C++实现
- ✅ 边界检查正确 (从1开始避免j-1/i-1越界)

## 🐛 已知问题与解决方案

### 1. PATTERNS数组大小错误
**问题**:
```rust
error: expected an array with a size of 73, found one with a size of 72
```

**原因**:
- 数组声明为 `[[i32; 10]; 73]` (73个元素)
- 实际提供72个元素 (包括end marker `[0,0,0,0,255,0,0,0,0,0]`)

**解决**:
```rust
// 修正前
const PATTERNS: [[i32; 10]; 73] = [ ... ];

// 修正后
const PATTERNS: [[i32; 10]; 72] = [ ... ];
```

**原因分析**:
- C++: `Patterns[100][10]` 有100个槽位, L2使用72个 (索引0-71)
- Rust: 直接定义72个元素数组
- End marker `[0,0,0,0,255,0,0,0,0,0]` 是第72个元素 (索引71), 不是额外的第73个

## 📚 技术细节

### 透明度系统
**坐标映射**:
```
dungeon[i][j]          → trans_val[xx][yy]
(DMAXX×DMAXY)           (MAXDUNX×MAXDUNY)
(40×40)                 (112×112)

xx = 16 + i * 2
yy = 16 + j * 2

示例:
dungeon[0][0] → trans_val[16][16]
dungeon[1][0] → trans_val[18][16]
dungeon[0][1] → trans_val[16][18]
```

**2x2块结构**:
```
trans_val[xx][yy]      trans_val[xx+1][yy]
  ┌─────────────────────┐
  │                     │
  │  dungeon[i][j]      │
  │                     │
  └─────────────────────┘
trans_val[xx][yy+1]    trans_val[xx+1][yy+1]
```

### 门廊道检测逻辑
**水平廊道**:
```
  j-1:  #####    (tile 3)
  j:    ..5..    (tile 2/5)
  j+1:  #####    (tile 3)
        ↑   ↑
        i   scan_i
```

**垂直廊道**:
```
  i-1   i   i+1
   #    .    #   (j)
   #    .    #   (j+1)
   #    4    #   (scan_j)
   #    .    #
```

### 瓷砖替换映射
```
FixDirtTiles规则:
10 → 143  (无下邻居12)
11 → 144  (无右邻居13)
13 → 146  (无右邻居11 或 无下邻居11)
14 → 147  (无下邻居12)
15 → 148  (无右邻居14)

FixDoors规则:
4 (垂直门) → 7  (有上墙3)
5 (水平门) → 9  (有左墙3)
```

1. **边界检查模式**:
