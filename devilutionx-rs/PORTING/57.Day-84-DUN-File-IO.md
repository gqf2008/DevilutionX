### LoadFileInMem (C++)

**Location**: Source/utils/file_util.hpp (lines 45-62)

```cpp
template <typename T = uint8_t>
std::unique_ptr<T[]> LoadFileInMem(const char *path, size_t *fileLen = nullptr)
{
    AssetRef ref = FindAsset(path);
    if (!ref.ok()) {
        return nullptr;
    }

    size_t len;
    std::unique_ptr<T[]> buf { LoadAsset<T>(ref, len) };
    if (fileLen != nullptr)
        *fileLen = len;

    return buf;
}
```

### .dun File Format

**Binary Layout**:
```
Offset | Size | Type     | Description
-------|------|----------|-------------
0x00   | 2    | uint16   | Width (little-endian)
0x02   | 2    | uint16   | Height (little-endian)
0x04   | W*H*2| uint16[] | Tile data (row-major, little-endian)
```

**Example**: diab1.dun (11x12 area)
```
Header: 0x0B 0x00 0x0C 0x00 (width=11, height=12)
Data:   264 bytes (11 * 12 * 2 = 264)
Total:  268 bytes
```

### PlaceDunTiles (C++)

**Location**: Source/levels/gendung.cpp (lines 1043-1063)

```cpp
void PlaceDunTiles(const uint16_t *dunData, Point position, int tiles)
{
    int width = SDL_SwapLE16(dunData[0]);
    int height = SDL_SwapLE16(dunData[1]);

    const uint16_t *tileLayer = &dunData[2];

    for (int j = 0; j < height; j++) {
        for (int i = 0; i < width; i++) {
            auto tileId = static_cast<uint8_t>(SDL_SwapLE16(tileLayer[j * width + i]));
            if (tileId != 0) {
                WorldTilePosition tile = position + Displacement { i, j };
                dungeon[tile.x][tile.y] = tileId;
            }
        }
    }
}
```

**Key Points**:
1. First 2 uint16s are width/height (little-endian)
2. Tile data is row-major (y-major loop)
3. Tile value 0 = skip (don't overwrite)
4. Position is top-left corner
5. Tiles parameter unused (legacy)

### Task 1: load_dun_file() - Binary File Reading (50 lines)

**Location**: drlg_l4.rs (replace placeholder at line 1439)

**Function Signature**:
```rust
/// Load .dun file and place tiles in dungeon
///
/// # Arguments
/// * `filename` - Path to .dun file (e.g., "levels/l4data/diab1.dun")
/// * `dungeon` - Dungeon instance
/// * `x` - Top-left X position
/// * `y` - Top-left Y position
///
/// # Returns
/// `true` if successful, `false` if file not found or invalid
fn load_dun_file(&mut self, filename: &str, dungeon: &mut Dungeon, x: i32, y: i32) -> bool
```

**Implementation Steps**:

1. **File Reading**:
```rust
use std::fs::File;
use std::io::{Read, Result};

// Open file
let mut file = match File::open(filename) {
    Ok(f) => f,
    Err(_) => return false, // File not found
};

// Read entire file
let mut buffer = Vec::new();
if file.read_to_end(&mut buffer).is_err() {
    return false; // Read error
}

// Validate minimum size (4 bytes header)
if buffer.len() < 4 {
    return false; // Invalid file
}
```

2. **Parse Header** (little-endian):
```rust
// Parse width (bytes 0-1)
let width = u16::from_le_bytes([buffer[0], buffer[1]]) as usize;

// Parse height (bytes 2-3)
let height = u16::from_le_bytes([buffer[2], buffer[3]]) as usize;

// Validate data size
let expected_size = 4 + (width * height * 2);
if buffer.len() != expected_size {
    return false; // Size mismatch
}
```

3. **Parse Tile Data**:
```rust
// Extract tile data (bytes 4+)
let tile_data = &buffer[4..];

for j in 0..height {
    for i in 0..width {
        let offset = (j * width + i) * 2;
        let tile_id = u16::from_le_bytes([
            tile_data[offset],
            tile_data[offset + 1]
        ]) as u8;

        // Skip tile 0 (transparent)
        if tile_id == 0 {
            continue;
        }

        // Place tile in dungeon
        let px = x + i as i32;
        let py = y + j as i32;

        // Bounds check
        if px >= 0 && px < DMAXX && py >= 0 && py < DMAXY {
            dungeon.dungeon[px as usize][py as usize] = tile_id;
        }
    }
}

true // Success
```

**Error Handling**:
- File not found → return false
- Invalid header → return false
- Size mismatch → return false
- Out of bounds → skip tile (silent)

```rust
/// Load Diablo quad layouts for Level 16
///
/// Loads 4 special room layouts (diab1/2/3/4) around l4_hold center.
/// Preflag determines whether to use "before stairs" (2b/3b/4b) or
/// "after stairs" (2a/3a/4a) variants.
///
/// # Arguments
/// * `dungeon` - Dungeon instance
/// * `preflag` - true = before stairs (use b variants), false = after (use a)
fn load_diablo_quads(&mut self, dungeon: &mut Dungeon, preflag: bool) {
    // Quad 1 (SW): diab1.dun (always loaded, no a/b variant)
    let quad1_x = self.l4_hold_x + 4;
    let quad1_y = self.l4_hold_y + 4;
    self.load_dun_file("levels/l4data/diab1.dun", dungeon, quad1_x, quad1_y);

    // Quad 2 (NE): diab2a.dun or diab2b.dun
    let quad2_x = 27 - self.l4_hold_x;
    let quad2_y = 1 + self.l4_hold_y;
    let quad2_file = if preflag {
        "levels/l4data/diab2b.dun"
    } else {
        "levels/l4data/diab2a.dun"
    };
    self.load_dun_file(quad2_file, dungeon, quad2_x, quad2_y);

    // Quad 3 (NW): diab3a.dun or diab3b.dun
    let quad3_x = 1 + self.l4_hold_x;
    let quad3_y = 27 - self.l4_hold_y;
    let quad3_file = if preflag {
        "levels/l4data/diab3b.dun"
    } else {
        "levels/l4data/diab3a.dun"
    };
    self.load_dun_file(quad3_file, dungeon, quad3_x, quad3_y);

    // Quad 4 (SE): diab4a.dun or diab4b.dun
    let quad4_x = 28 - self.l4_hold_x;
    let quad4_y = 28 - self.l4_hold_y;
    let quad4_file = if preflag {
        "levels/l4data/diab4b.dun"
    } else {
        "levels/l4data/diab4a.dun"
    };
    self.load_dun_file(quad4_file, dungeon, quad4_x, quad4_y);
}
```

**Key Points**:
1. Quad 1 (diab1.dun) always loaded (no a/b variant)
2. Quads 2/3/4 use preflag to select a/b variant
3. Positions calculated from l4_hold
4. Files loaded via load_dun_file()
