## Summary

Implemented the **UberRoom recursive subdivision system** for L4 Hell dungeon generation. This is the core algorithm that creates the organic, interconnected room layout characteristic of Hell levels.

### Key Features

1. **Room Structure** (11 lines)
   - Position (x, y)
   - Dimensions (width, height)
   - Used for collision detection

2. **DungeonMask** (40x40 bitmap)
   - Tracks room occupancy in first quadrant
   - Prevents room overlap
   - Used for mirroring to other quadrants

3. **MapRoom** (15 lines)
   - Marks room area in dungeon_mask
   - Bounds checking for quadrant limits
   - Clamps to MAXDUNX/2, MAXDUNY/2

4. **CheckRoom** (20 lines)
   - Validates room placement
   - Checks for overlap with existing rooms
   - Enforces boundary constraints (x > 0, y > 0)

5. **GenerateRoom** (100 lines)
   - **Recursive subdivision algorithm**
   - 20 attempts to place first room
   - Random even dimensions (2-6 width/height)
   - Vertical/horizontal layout with 75% rotation chance
   - Places two adjacent rooms per call
   - Recursively subdivides both rooms

6. **FirstRoom** (30 lines)
   - Entry point for UberRoom system
   - Special handling for Level 16 (14×14 fixed size)
   - Random dimensions for normal levels (2-6)
   - Centered random position in first quadrant
   - Stores l4_hold for Diablo's Lair

## Technical Details

### Algorithm Flow

```
FirstRoom(level)
├─ Determine room size (quest or random)
├─ Choose random position in quadrant
├─ MapRoom(initial)
└─ GenerateRoom(initial, random_layout)
   ├─ Rotate layout? (75% chance)
   ├─ Try 20 times to place Room1
   │  ├─ Random even dimensions (2-6)
   │  ├─ Position: left/above parent
   │  ├─ CheckRoom(bounds + collision)
   │  └─ MapRoom if valid
   ├─ Try to place Room2 (adjacent)
   │  ├─ CheckRoom(bounds + collision)
   │  └─ MapRoom if valid
   └─ Recursive calls
      ├─ GenerateRoom(Room1, layout)
      └─ GenerateRoom(Room2, layout)
```

### UberRoom Properties

- **Minimum room size**: 2×2
- **Maximum room size**: 6×6 (with padding)
- **Placement retries**: 20 per room
- **Layout rotation**: 75% chance per level
- **Subdivision depth**: Limited by room size constraints

### DungeonMask Usage
