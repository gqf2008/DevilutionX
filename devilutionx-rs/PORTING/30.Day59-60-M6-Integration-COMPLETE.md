## 🎓 关键技术实现

### 1. Cathedral 程序生成算法

**核心流程** (drlg_l1.rs):
```rust
1. init_dungeon()           // 初始化地牢数据结构
2. first_room()             // 创建初始房间(确保至少2个房间)
3. make_rooms()             // 递归分割创建更多房间
4. make_chambers()          // 连接房间,形成连通的地牢
5. make_filler()            // 填充墙壁和空隙
6. fix_tile_patterns()      // 修正瓦片模式(L型拐角等)
7. place_minisets()         // 放置预设图案(楼梯/灯具/水域)
```

**3-Chamber 系统**:
- **Chamber 1**: 主区域(至少2个房间)
- **Chamber 2**: 次要区域(可选)
- **Chamber 3**: 小区域(可选)
- 通过 `make_chambers()` 连接,确保连通性

### 2. Town 预制地图系统

**加载流程** (town.rs):
```rust
1. 加载 TOWN.DUN 文件(4个扇区,每个22x22瓦片)
2. fill_sector() 填充扇区到地牢数组
3. 标记18种特殊瓦片(入口/出口/传送点/NPC位置)
4. 初始化 Hive/Grave 动态元素
5. 设置5种入口点(TownEntry枚举)
```

**动态元素**:
- **Hive**: 可开启/关闭(Hellfire任务)
- **Grave**: 可开启/关闭(King Leoric任务)

### 3. 主题房间系统

**主题类型** (themes.rs):
- **可重复**: Shrine, SkelRoom, Library, Barrel, Torture
- **单次限制**: ArmorStand, WeaponRack, Treasure, Cauldron
- **喷泉限制**: 每种喷泉每关只能出现1次(4种)

**未来工作**:
- 17个 `Theme_*()` 实现函数(~600行代码)
- 需要对象系统和怪物系统集成

### 4. Miniset 模板系统

**功能**: 在程序生成的地牢中嵌入预设图案

**4种 Miniset** (drlg_l1.rs):
1. **Lamps**: 灯具装饰(6×6)
2. **Stairs Down**: 下楼梯(4×4)
3. **Stairs Up**: 上楼梯(4×5)
4. **Water In**: 水域(6×6)

**匹配算法**:
```rust
fn miniset_matches(dungeon, x, y, search_pattern) -> bool {
    for dy in 0..height {
        for dx in 0..width {
            if search[dy][dx] != 0 && dungeon.piece[x+dx][y+dy] != search[dy][dx] {
                return false;
            }
        }
    }
    true
}
```

### 5. 触发器系统

**触发器类型** (trigs.rs):
- **楼梯上**: 回到上一层
- **楼梯下**: 进入下一层
- **传送点**: Town Portal (4种: Catacombs/Caves/Hell/Crypt)
- **任务触发**: 特定任务相关的触发器

**Warp Open逻辑**:
```rust
pub fn is_warp_open(msg: TriggerMessage, player_level: u8, is_multiplayer: bool) -> bool {
    match msg {
        TriggerMessage::TownWarpCatacombs => player_level >= 5,
        TriggerMessage::TownWarpCaves => player_level >= 9,
        TriggerMessage::TownWarpHell => player_level >= 13,
        TriggerMessage::TownWarpCrypt => !is_multiplayer, // 单人任务
        _ => true,
    }
}
```
