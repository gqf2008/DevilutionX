```rust
pub enum EquipError {
    SlotOccupied,                  // 槽位已占用
    InvalidSlot,                   // 无效槽位

    StrengthRequired(u8),          // 力量不足
    MagicRequired(u8),             // 魔法不足
```


### 1. 类型安全的错误处理

**Rust 优势**:
```rust
// 错误携带详细信息
match equipment.can_equip(&player, &item, slot) {
    Ok(()) => { /* 可以装备 */ },
    Err(EquipError::StrengthRequired(str)) => {
        println!("需要 {} 点力量", str);
    },
    Err(err) => println!("{}", err),
}
```

**vs C++**:
```cpp
// 仅返回 bool，需额外检查
```

```rust
// Bard 双持剑/锤
if player_stats.class == HeroClass::Bard {
    let both_sword_or_mace =
        matches!(occupied_item.item_type, ItemType::Sword | ItemType::Mace) &&
        matches!(item.item_type, ItemType::Sword | ItemType::Mace);

    if both_sword_or_mace && both_one_handed {
```

### 3. 槽位自动选择

**Auto-equip 策略**:
```rust
let candidate_slots = match item_loc {
    ItemLocation::Helm => vec![EquipSlot::Head],
    ItemLocation::Ring => vec![EquipSlot::RingLeft, EquipSlot::RingRight], // 优先左
    ItemLocation::OneHand => vec![EquipSlot::HandRight, EquipSlot::HandLeft], // 优先右
    // ...
};

for slot in candidate_slots {
    if can_equip(player, &item, slot).is_ok() {
        return equip(player, item, slot);
    }
}
```

**符合玩家习惯**: 武器优先右手，戒指优先左手
