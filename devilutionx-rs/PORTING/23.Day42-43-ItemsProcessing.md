```cpp
struct AnimationInfo {
    int currentFrame;
    int numberOfFrames;

    void processAnimation() {
        currentFrame++;
        if (currentFrame >= numberOfFrames)
            currentFrame = 0;
    }

    bool isLastFrame() const {
        return currentFrame == numberOfFrames - 1;
    }
};
```

**Rust 实现** (src/game/items_processing.rs:23-50):
```rust
#[derive(Debug, Clone)]
pub struct AnimationInfo {
    pub current_frame: i32,       // Current animation frame
    pub number_of_frames: i32,    // Total number of frames
}

impl AnimationInfo {
    pub fn new(number_of_frames: i32) -> Self {
        Self {
            current_frame: 0,
            number_of_frames,
        }
    }

    pub fn process_animation(&mut self) {
        self.current_frame += 1;
        if self.current_frame >= self.number_of_frames {
            self.current_frame = 0;
        }
    }

    pub fn is_last_frame(&self) -> bool {
        self.current_frame == self.number_of_frames - 1
    }
}
```

## 🎓 关键技术点

### 1. 魔法石动画特殊处理

魔法石 (Magic Rock) 是唯一有两组独立动画帧的物品：
- **地面帧** (Bottom): 0-9 (10 帧)
- **悬空帧** (Middle): 10-18 (9 帧)

每组帧独立循环，不会互相干扰。

### 2. ItemDoppel 多人同步机制

每帧只检查一行 (Y 坐标 16-95)，循环扫描整个地图：
- 避免单帧性能峰值
- 保证所有位置最终都会被检查
- 96-16+1 = 81 行，每帧 1 行，约 1.35 秒扫描一遍完整地图 (60 FPS)

### 3. 动画音效同步

在动画中间帧播放物品落地音效：
```rust
if item.anim_info.current_frame == (item.anim_info.number_of_frames - 1) / 2 {
    // PlaySfxLoc(ItemDropSnds[...], item.position);
}
```

### 4. SelectionRegion 状态管理

物品动画完成时，强制设置为 `Bottom` (地面层级)：
```rust
if item.anim_info.is_last_frame() {
    item.selection_region = SelectionRegion::Bottom;
    item.anim_flag = false;
```
