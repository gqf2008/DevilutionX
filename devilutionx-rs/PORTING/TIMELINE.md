## 三、🎮 可以玩游戏的那一天

### 📆 **2025-12-29 (周日)**

这一天你可以:

1. **启动游戏**
   ```
   cargo run --release
   ```

2. **看到Blizzard Logo** (3秒)

3. **主菜单**
   ```
   ┌─────────────────────────┐
   │   Single Player         │
   │   Multi Player (灰色)    │
   │   Exit Diablo           │
   └─────────────────────────┘
   ```

4. **创建角色**
   - 选择"战士" (图标显示战士形象)
   - 输入名字"勇士"
   - 看到属性: 力量30, 魔法10, 敏捷20, 生命25

5. **进入Tristram镇**
   - 看到石头地面
   - 看到小木屋
   - 看到NPC (暂时不能对话)
   - 你的角色站在镇中心

6. **走到地下城入口**
   - 点击地面 → 角色走过去
   - 点击地下城入口 → 进入第1层

7. **地下城第1层**
   - 看到阴暗的石墙
   - 看到火把的光照
   - 突然,一只僵尸出现!

8. **第一次战斗**
   - 僵尸慢慢走向你
   - 点击僵尸 → 你挥剑攻击
   - 僵尸反击 → 你掉血
   - 再点击几次 → 僵尸倒下
   - 地上出现一把剑

9. **拾取装备**
   - 点击剑 → 自动拾取
   - 按I打开背包
   - 拖动剑到装备栏
   - 你的攻击力提升了!

10. **保存并退出**
    - 按ESC
    - 选择"Save & Exit"
    - 回到主菜单

11. **重新进入**
    - 选择"勇士 Lv.1"
    - 继续游戏
    - 你还在地下城第1层
    - 装备和血量都保留

**这就是真正可玩的游戏!** 🎉

## 七、风险评估

### ⚠️ 可能延期的因素

1. **MPQ解析复杂度** (+2天)
   - libmpq绑定可能有问题
   - 缓解: 使用现成的mpq-rust crate

2. **渲染性能问题** (+1天)
   - 地图过大导致卡顿
   - 缓解: 只渲染可见区域

3. **寻路算法Bug** (+1天)
   - A*实现可能有死循环
   - 缓解: 使用成熟的pathfinding crate

4. **存档格式兼容** (+1天)
   - 与C++存档格式不一致
   - 缓解: 参考C++代码精确对齐
