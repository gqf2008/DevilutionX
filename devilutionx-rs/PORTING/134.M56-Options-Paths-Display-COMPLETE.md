## 2. 新增模块详情

### 2.1 paths.rs - 路径管理

**功能**:
- 平台特定路径检测 (Windows/macOS/Linux)
- 基础路径、偏好路径、配置路径、资源路径管理
- MPQ 文件搜索
- 便携模式支持 (diablo.ini 检测)

**核心 API**:
```rust
pub fn base_path() -> String;
pub fn pref_path() -> String;
pub fn config_path() -> String;
pub fn assets_path() -> String;
pub fn mpq_path(name: &str) -> Option<PathBuf>;
pub fn save_path(name: &str) -> PathBuf;
```

### 2.2 options.rs - 配置系统

**功能**:
- 完整的游戏配置选项
- INI 文件读写
- 全局单例访问
- 默认值管理

**配置分类**:
| 分类 | 选项数 | 描述 |
|------|--------|------|
| GameModeOptions | 2 | 游戏模式、共享版 |
| StartUpOptions | 3 | 启动选项 |
| AudioOptions | 7 | 音频设置 |
| GraphicsOptions | 16 | 图形设置 |
| GameplayOptions | 30+ | 游戏选项 |
| ControllerOptions | 3 | 控制器设置 |
| NetworkOptions | 3 | 网络设置 |
| LanguageOptions | 1 | 语言设置 |

**核心 API**:
```rust
pub fn options() -> RwLockReadGuard<'static, Options>;
pub fn options_mut() -> RwLockWriteGuard<'static, Options>;
pub fn load_options(path: &Path) -> Result<(), OptionsError>;
pub fn save_options(path: &Path) -> Result<(), OptionsError>;
```

### 2.3 display.rs - 显示管理

**功能**:
- 屏幕尺寸管理
- DPI 缩放
- 坐标转换 (逻辑 <-> 输出)
- 整数缩放计算
- 分辨率查找

**核心 API**:
```rust
pub fn get_screen_width() -> u16;
pub fn get_screen_height() -> u16;
pub fn is_fullscreen() -> bool;
pub fn get_dpi_scaling_factor() -> f32;
pub fn output_to_logical(x: i32, y: i32) -> (i32, i32);
pub fn logical_to_output(x: i32, y: i32) -> (i32, i32);
pub fn calculate_integer_scale(window: Size, base: Size) -> (u32, Size);
```
