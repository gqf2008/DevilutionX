### Day 77: L4 生成循环 + MakeMegas (~500 lines)

**实现内容**:

1. **generate() 主循环**
```rust
pub fn generate(&mut self, dungeon: &mut Dungeon, seed: u32, level: u8, entry: LevelEntry) -> bool {
    self.set_rng_seed(seed);

    loop {
        self.init_dungeon_flags();

        // Place UberRooms
        for i in 0..5 {
            self.create_uber_row(i);
        }

        // Connect rooms with halls
        for i in 0..4 {
            for j in 0..4 {
                if self.get_hall(x1, y1, x2, y2, dir) {
                    self.connect_hall(x1, y1, x2, y2, dir);
                }
            }
        }

        // Validate floor area
        if self.get_floor_area(dungeon) < 600 {
            continue;
        }

        // Apply MakeMegas
        self.make_megas(dungeon);

        // Place stairs
        if !self.place_stairs(dungeon, level, entry) {
            continue;
        }

        // Place decorations
        self.place_decorations(dungeon, level);

        break;
    }

    true
}
```

```rust
fn place_stairs(&mut self, dungeon: &mut Dungeon, level: u8, entry: LevelEntry) -> bool {
    // L4USTAIRS (Level 13-15)
    if !self.try_place_miniset(dungeon, &miniset_l4_ustairs()) {
        return false;
    }

    // L4DSTAIRS (Level 13-14)
    if level < 15 {
        if !self.try_place_miniset(dungeon, &miniset_l4_dstairs()) {
            return false;
        }
    }

    // L4PENTA (Level 15 only)
    if level == 15 {
        if !self.try_place_miniset(dungeon, &miniset_l4_penta()) {
            return false;
        }
    }

    // Town warp (specific levels)
    if matches!(entry, LevelEntry::TownWarp) {
        if !self.try_place_miniset(dungeon, &miniset_l4_twarp()) {
            return false;
        }
    }

    true
}
```

```rust
fn try_place_miniset(&mut self, dungeon: &mut Dungeon, miniset: &Miniset) -> bool {
    for _attempt in 0..100 {
        let sx = self.random_range(0, DMAXX - miniset.width);
        let sy = self.random_range(0, DMAXY - miniset.height);

        if self.miniset_matches(dungeon, miniset, sx, sy) {
            self.place_miniset_at(dungeon, miniset, sx, sy);
            return true;
        }
    }
    false
}
```

## 🔍 技术难点

### 1. UberRoom 系统
**挑战**: 15 种预定义房间布局，需要精确匹配 C++ 数据
**解决方案**:
- 提取 C++ UberRoom 数据到常量数组
- 单元测试验证每种房间类型
- 边界检查防止越界

### 2. 走廊连接算法
**挑战**: GetHall/ConnectHall 复杂逻辑，4 方向 + L 型弯曲
**解决方案**:
- 分解为 Horizontal/Vertical/L-Shape 子函数
- 使用状态机处理方向转换
- 可视化测试验证连接正确性

### 3. Diablo Quads
**挑战**: 需要加载外部 quad 数据文件
**解决方案**:
- 先使用硬编码数据验证逻辑
- 后期集成 MPQ 文件加载
- 或者将 quad 数据嵌入 Rust 常量

### 4. MakeMegas L4 版本
**挑战**: L4_CONV_TABLE 规则与 L3 不同
**解决方案**:
- 复用 L3 MakeMegas 框架
- 替换转换表为 L4_CONV_TABLE
- 单独测试 L4 瓦片转换
