## Lessons Learned

### 1. Distance Calculation Critical

**Issue**: Initial tests used Manhattan distance (`dx + dy`) instead of Chebyshev distance (`max(dx, dy)`).

**C++ Code**:
```cpp
// Source/engine/point.hpp:123
constexpr int WalkingDistance(Point target) const {
    return std::max(std::abs(x - target.x), std::abs(y - target.y));
}
```

**Solution**: Added `walking_distance()` method matching C++ exactly.

**Impact**: AI now correctly treats diagonal movement as 1 tile (not 2).

### 2. Integer Underflow Protection

**Issue**: Skeleton AI formula `35 - (4 * intelligence)` underflows if `intelligence > 8`.

**Vulnerable Code**:
```rust
let walk_chance = 35 - (4 * monster.intelligence as u32);  // Crash!
```

**Solution**: Clamp and use `min()`:
```rust
let intel_factor = (4 * monster.intelligence as u32).min(35);
let walk_chance = 35 - intel_factor;  // Safe!
```

**Impact**: Supports all intelligence values [0,255] safely.

### 3. RNG Abstraction for Testing

**Pattern**: `FnMut(u32) -> u32` trait for dependency injection.

**Benefit**: Full control over AI decisions in tests:
```rust
// Force success
let mut rng = |_max: u32| -> u32 { 0 };

// Force failure
let mut rng = |_max: u32| -> u32 { 100 };

// Sequence control
let mut call_count = 0;
let mut rng = |_max: u32| -> u32 {
    call_count += 1;
    match call_count {
        1 => 0,   // First call succeeds
        2 => 100, // Second call fails
        _ => 50,  // Others neutral
    }
};
```

**Impact**: Deterministic AI testing without actual randomness.
