## 🎯 核心实现: ConnectHall 算法

### C++ 参考
**文件**: `Source/levels/drlg_l2.cpp:1864-1963`
**功能**: 连接两个房间,从 `beginning` 到 `end`,雕刻走廊路径

### 关键特性

1. **边界碰撞检测** (Boundary Collision)
   - 检测地图边缘 (x/y ≤ 1 或 ≥ 38)
   - 自动反转方向避免越界

2. **转角碰撞检测** (Corner Collision)
   - 检测房间角标记 (`'A'`, `'B'`, `'C'`, `'E'`)
   - 智能转向避免穿透房间

3. **走廊雕刻** (Corridor Carving)
   - 标记路径为 `','` (走廊)
   - 可选宽度扩展 (`f_minus_flag`, `f_plus_flag`)
   - 自动在房间入口创建门 (`'D'`)

4. **方向调整** (Direction Adjustment)
   - 根据到目标距离动态调整方向
   - 水平距离优先: `dx > dy` → 倾向水平移动 (2x weight)
   - 垂直距离优先: `dy >= dx` → 倾向垂直移动 (5x weight)
   - 接近目标时精细调整 (dy < 10, dx < 10)

5. **特殊情况处理**
   - 完全对齐时强制方向 (dx == 0 或 dy == 0)
   - 几乎对齐时优先对齐方向 (dy == 1, dx == 1)

### Rust 实现细节

```rust
fn connect_hall(&mut self, hall: &HallNode) {
    let mut beginning = hall.beginning;
    let mut end = hall.end;
    let mut current_dir = hall.direction;

    // Main loop: carve corridor from beginning to end
    while beginning != end {
        // 1. Boundary collision detection
        if beginning.x >= 38 && current_dir == HallDirection::Right {
            current_dir = HallDirection::Left;
        }
        // ... (similar checks for all 4 directions)

        // 2. Corner collision detection
        let current_char = self.get_predungeon(beginning);
        if current_char == 'C' && (Up or Left) {
            current_dir = HallDirection::Right;
        }
        // ... (similar checks for A/B/E corners)

        // 3. Move in current direction
        beginning += DIR_ADD[current_dir];

        // 4. Place corridor tile
        if self.get_predungeon(beginning) == ' ' {
            // Widen corridor (random)
            if f_minus_flag { place_hall_ext(perpendicular -1) }
            if f_plus_flag { place_hall_ext(perpendicular +1) }
            self.set_predungeon(beginning, ',');
        }

        // 5. Adjust direction based on distance
        let dx = abs(end.x - beginning.x);
        let dy = abs(end.y - beginning.y);

        if dx > dy {
            // Favor horizontal: 2*dx chance (max 30%)
            if random(min(2*dx, 30)) {
                current_dir = (end.x > beginning.x) ? Right : Left;
            }
        } else {
            // Favor vertical: 5*dy chance (max 80%)
            if random(min(5*dy, 80)) {
                current_dir = (end.y > beginning.y) ? Down : Up;
            }
        }

        // ... (fine-tuning when close to goal)
    }
}
```

## 🎨 核心实现: Minisets 系统

### 什么是 Miniset?

Miniset 是一种**模式替换系统**,用于装饰地牢:

1. **搜索模式** (`search`): 在 predungeon 中匹配特定图案
2. **替换模式** (`replace`): 匹配成功后替换为新瓦片

### Miniset 放置算法

#### place_miniset_at() - 精确放置

```rust
fn place_miniset_at(&mut self, miniset: &Miniset, pos: Point) -> bool {
    // 1. Bounds check
    if pos.x + width > DMAXX || pos.y + height > DMAXY {
        return false;
    }

    // 2. Pattern matching
    for y in 0..height {
        for x in 0..width {
            let search_val = miniset.search[y][x];
            if search_val == 0 { continue; } // Wildcard

            let matches = match search_val {
                1 => predungeon == '#',  // Wall
                2 => predungeon == '.',  // Floor (corridor)
                3 => predungeon == '.',  // Floor (room)
                4 => predungeon == ' ',  // Void
                7 => predungeon == '#' || predungeon == 'D', // Wall or Door
                _ => false,
            };

            if !matches { return false; }
        }
    }

    // 3. Apply replacement
    for y in 0..height {
        for x in 0..width {
            if miniset.replace[y][x] != 0 {
                // Update dungeon tile (marked as 'M' in tests)
                self.predungeon[pos.x + x][pos.y + y] = 'M';
            }
        }
    }

    true
}
```
