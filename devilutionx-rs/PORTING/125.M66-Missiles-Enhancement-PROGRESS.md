# M66: Missiles Enhancement - Day 2 Progress

## 概述
增强 missiles.rs 模块，添加完整的导弹数据系统、碰撞检测和伤害计算。

## Day 2 完成的工作

### 1. 扩展 MissileData 系统
- `get_missile_data()` 扩展到支持 40+ 种导弹类型
  - MagmaBall, Acid, AcidSplat, AcidPuddle
  - TownPortal, RedPortal, Teleport
  - Firewall, Nova, ChainLightning, Apocalypse
  - BloodStar, Mana, Magi, Healing, HealOther
  - Immolation, LightningWall, Reflect
  - 所有5种符文类型 (Rune1-5)
  - BigExplosion, HorkSpawn 等

### 2. 新增处理函数 (14个)
- `process_bone_spirit()` - 追踪导弹，造成目标1/3最大HP伤害
- `process_elemental()` - 火元素追踪导弹
- `process_flame_wave()` - 火焰波行进
- `process_fire_wall()` - 静止火墙
- `process_town_portal()` - 传送门动画
- `process_apocalypse()` - 区域伤害效果
- `process_chain_lightning()` - 多目标闪电
- `process_nova()` - 径向闪电新星
- `process_stone_curse()` - 石化效果
- `process_blood_star()` - 血魔法投射物
- `process_acid_splat()` - 酸液溅射
- `process_acid_puddle()` - 持续酸液伤害
- `process_rhino()` - 怪物冲撞攻击
- `process_generic_missile()` - 通用处理函数

### 3. 更新 MissileManager.process_missiles_full()
- 完整的导弹类型分派
- 支持所有新增导弹类型
- 正确的动画处理
- 自动清理过期导弹

### 4. 新增 MissileManager.process_missiles_with_state()
- 带完整地牢状态的导弹处理
- 使用 DungeonState 进行碰撞检测
- 支持 HitType 检测（Monster/Player/Wall/Object）
- 自动删除碰撞后的导弹

### 5. 扩展 MissileID 枚举
新增枚举值:
- GuardianTentacle (103) - 守护九头蛇触手
- ElementalBall (104) - 元素球投射物
- StoneCurseMissile (105) - 石化效果
- SpecArrow (106) - 特殊箭矢
- Rune1-5 (107-111) - 符文别名
