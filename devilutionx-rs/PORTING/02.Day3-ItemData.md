## Technical Challenges

### Issue: Macro Parameter Count Error
**Problem**: `udat!()` macro requires exactly 25 parameters (6 header + 6 powers × 3 params each), but Thundercall only provided 23 parameters (missing 6th power's `Invalid` set).

**Error**:
```
error: unexpected end of macro invocation
   --> src\game\item_dat.rs:1452
```

**Solution**: Added missing 6th power parameter:
```rust
// Before (23 params)
udat!("Thundercall", 0, UniqueBaseItem::WarStaff, 18, 5, 28500,
      ItemEffectType::ToHit, 35, 35,
      ItemEffectType::SetDam, 1, 50,
      ItemEffectType::LightDam, 1, 40,
      ItemEffectType::Mag, 10, 10,
      ItemEffectType::Charges, 60, 60),

// After (25 params)
udat!("Thundercall", 0, UniqueBaseItem::WarStaff, 18, 5, 28500,
      ItemEffectType::ToHit, 35, 35,
      ItemEffectType::SetDam, 1, 50,
      ItemEffectType::LightDam, 1, 40,
      ItemEffectType::Mag, 10, 10,
      ItemEffectType::Charges, 60, 60,

```
