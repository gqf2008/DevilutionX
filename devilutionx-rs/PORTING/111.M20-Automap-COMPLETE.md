## 📋 概述

M20 Automap System 实现了游戏内地图覆盖层功能，用于显示玩家探索过的区域。该系统是从 C++ `automap.cpp` (1,956行) 精确移植而来。

## 🎯 实现目标

### 核心结构 (100%)

1. **AutomapTileType** (60种瓦片类型)
   - 基础类型: None, Diamond, Vertical, Horizontal, Cross, Corner
   - 洞穴类型: CaveCross, CaveHorizontal, CaveVertical, CaveWoodCross 等
   - 河流类型: River, RiverCorner*, RiverFork*, RiverLeft*, RiverRight*
   - 熔岩类型: Lava, SELava, SWLava, NELava, NWLava, HorizontalLavaThin 等
   - 特殊类型: PentagramClosed, PentagramOpen, Bridge

2. **AutomapTileFlags** (8种标志)
   ```rust
   VERTICAL_DOOR      // 垂直门
   HORIZONTAL_DOOR    // 水平门
   VERTICAL_ARCH      // 垂直拱门
   HORIZONTAL_ARCH    // 水平拱门
   VERTICAL_GRATE     // 垂直栅格
   HORIZONTAL_GRATE   // 水平栅格
   DIRT               // 土地
   STAIRS             // 楼梯
   ```

3. **AutomapTile** (瓦片定义)
   - `tile_type: AutomapTileType`
   - `flags: AutomapTileFlags`
   - `has_flag()` / `has_any_flag()` 方法

### AutomapManager (100%)

```rust
pub struct AutomapManager {

}
```
