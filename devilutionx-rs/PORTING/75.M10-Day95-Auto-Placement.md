// C++ version
bool AutoPlaceItemInInventory(Player &player, const Item &item, bool sendNetworkMessage) {
    std::optional<int> targetSlot = FindSlotForItem(player, itemSize);
    if (targetSlot) {
        AddItemToInvGrid(player, *targetSlot, player._pNumInv, itemSize, sendNetworkMessage);
        return true;
    }

// Rust version (更简洁的返回值)
pub fn auto_place(&mut self, item: Item, item_size: ItemSize) -> Result<usize, &'static str> {
    if let Some(slot) = self.find_empty_slot(item_size) {
        self.add_item(item, slot, item_size)?;
        Ok(slot)
    } else {
        Err("Inventory full")
    }
}

bool AutoPlaceItemInBelt(Player &player, const Item &item, bool persistItem, bool sendNetworkMessage) {
    if (!CanBePlacedOnBelt(player, item)) return false;

    for (Item &beltItem : player.SpdList) {
        if (beltItem.isEmpty()) {
            if (persistItem) {
                beltItem = item;

                RedrawComponent(PanelDrawComponent::Belt);

            return true;
        }
    }
    return false;

        Err("Belt full")
    }
}

## 🎯 技术亮点

### 1. 精确的 Grid Marking 系统

**设计理念**:
- 左下角单元格 (bottom-left) 存储 **正值** item_index
- 其他单元格存储 **负值** -(item_index + 1)
- 允许快速定位物品主单元格

**优势**:
- ✅ **O(1) 主单元格识别**: `grid[i] >= 0`
- ✅ **快速物品索引提取**: `abs(grid[i]) - 1`
- ✅ **UI 渲染优化**: 只绘制主单元格的物品图标

**示例**:
```rust
// 2×3 armor at slot 0, item_index = 0
grid[0] = -1   grid[1] = -1   // Top row
grid[10] = -1  grid[11] = -1  // Middle row
grid[20] = 0   grid[21] = -1  // Bottom row (grid[20] is primary)
```

---

### 2. 智能的放置优先级策略

**设计理念**:
- Height 1 物品: 优先填充最后一行 (药水/卷轴常用，快速拿取)
- Height 2 物品: 列优先遍历 (盔甲/盾牌，避免碎片化)
- Height 3 物品: 固定范围搜索 (大型武器，专用区域)

**优势**:
- ✅ 减少背包碎片化
- ✅ 提高空间利用率
- ✅ 符合玩家使用习惯

---

### 3. 金币堆叠的三步策略

**设计理念**:
1. **Step 1: Top off existing** - 最小化堆数，优先填满
2. **Step 2: Last row** - 优先使用底部空间 (常用物品区)
3. **Step 3: Remaining** - 从右下角向左上填充 (自然顺序)

**优势**:
- ✅ 最小化金币堆数量
- ✅ 保持背包整洁
- ✅ 符合 C++ 原版行为
