### 功能
- 游戏tick时序管理
- 网络回合发送/接收
- 动画进度计算
- 后台线程处理

### 主要结构
```rust
pub struct NThreadState {
    should_run: Arc<AtomicBool>,
    sync_countdown: i8,
    packet_countdown: i8,
    turns_in_transit: u32,
    last_tick: Instant,
    tick_delay: Duration,
}

pub struct NThreadManager {
    state: Arc<Mutex<NThreadState>>,
```
