## 🎓 技术要点

### 1. 标志位系统
使用位掩码表示物品类型:
```rust
pub struct AffixItemType(pub u32);

impl AffixItemType {
    pub const SWORD: Self = Self(1 << 3);
    pub const ALL_WEAPONS: Self = Self(
        Self::SWORD.0 | Self::AXE.0 | Self::MACE.0 | ...
    );

    pub fn contains(&self, other: Self) -> bool {
        (self.0 & other.0) != 0
    }
}
```

### 2. 权重随机选择


### 3. 线性值缩放
```rust
pub fn pl_val(value: i32, param1: i32, param2: i32,
              min_val: i32, max_val: i32) -> i32 {
    // 将 [param1, param2] 范围的值
    // 线性映射到 [min_val, max_val]
    min_val + (value - param1) * (max_val - min_val) / (param2 - param1)
}
```
