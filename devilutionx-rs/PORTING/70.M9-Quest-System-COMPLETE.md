### 1. Type-Safe Event System (类型安全事件系统)

```cpp
// C++: 字符串或整数标识, 运行时错误
```

### 2. Trait-Based Abstraction (Trait抽象)

**优势**:
- 解耦quests.rs和town.rs (避免循环依赖)

```rust
    fn town_open_hive(&mut self);
    fn town_close_hive(&mut self);
    fn town_open_grave(&mut self);
    fn town_close_grave(&mut self);
}

// 生产代码

// 测试代码

```

### 3. Exhaustive Match (穷尽匹配)

**C++ 问题**:
```cpp
// C++: switch容易遗漏case
switch (monsterId) {
    case BUTCHER: CompleteQuest(Q_BUTCHER); break;
    case SKELKING: CompleteQuest(Q_SKELKING); break;
    // 忘记添加新怪物时不会报错
}
```

**Rust 解决**:
```rust
match monster_id {
    MonsterId::Butcher => self.complete_quest(QuestId::Butcher),
    MonsterId::SkeletonKing => self.complete_quest(QuestId::SkelKing),
    // ... 编译器强制处理所有变体
    // 添加新怪物时自动提示
}
```

### 4. Immutable State Management (不可变状态管理)

**C++ 问题**:
```cpp
// C++: 全局可变状态
Quest Quests[24]; // 任何代码都能修改
```

**Rust 解决**:
```rust
pub struct QuestManager {
    quests: [Quest; 24], // 私有字段, 只能通过方法修改
    // ...
}

impl QuestManager {
    pub fn get_quest(&self, id: QuestId) -> &Quest { /* 只读访问 */ }
    pub fn get_quest_mut(&mut self, id: QuestId) -> &mut Quest { /* 可写访问 */ }
}
```

**优势**:
- 控制访问权限
- 防止意外修改
- 便于并发安全
