## 📝 开发笔记

### 架构决策
1. **模块化设计**: 每个 Rust 模块对应 C++ 的一组相关文件
2. **数据驱动**: 游戏数据与逻辑分离，便于修改和测试
3. **类型安全**: 使用 Rust 强类型系统防止运行时错误
4. **无全局状态**: 使用依赖注入替代 C++ 全局变量

### 技术栈
- **随机数**: 自实现 Diablo 兼容的 PRNG
- **渲染**: 8-bit 索引色调色板系统
- **坐标系**: 等轴测投影 (64x32 瓦片)
- **精灵格式**: CLX (DevilutionX 运行时格式)

### 已知问题
1. `load_sprite.rs` 中 CEL/CL2→CLX 转换待实现
2. `scrollrt.rs` 缺少完整渲染循环
3. 网络模块仅有基础框架
